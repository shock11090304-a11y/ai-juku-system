2次関数 — 平方完成と頂点

「次へ／戻る」で図が1ステップずつ完成。スライダー a, p, q を動かすと 標準形 y = a(x − p)² + q の放物線・頂点・軸が即連動します。

この単元の最重要ポイント = 標準形 y = a(x − p)² + q を読むこと。頂点は (p, q)、軸は x = p。a が開き方と向き、p が左右、q が上下を決めます。

標準形と頂点

y = a(x − p)² + q。頂点 (p, q)、軸 x = p。スライダーで a・p・q を変えると放物線が動きます。

a = 1.0
p = 0.0
q = 0.0
y = 1(x − 0)² + 0 　頂点 (0.0, 0.0) 　軸 x = 0.0
