# 中学2年生 英文法 総復習問題集

中2で習う文法を1年分まとめて復習する配布用問題集（問題編／解答解説編の2冊）。

**同じ12単元を3周する**構成。部が進むと一文が長くなり、一文の中で決めることが増える。
部ごとに単元を割り振っていないので、生徒は「今は◯◯の練習」と身構えずに解くことになる。

## 使い方

```bash
WORKBOOK_DIR=scripts/chugaku2_eigo_soufukushu python3 scripts/eng_kokkoritsu_nankan/check.py
WORKBOOK_DIR=scripts/chugaku2_eigo_soufukushu python3 scripts/eng_kokkoritsu_nankan/build.py
```

★**機械（組版・機械ゲート18種・盲検証ハーネス）は姉妹編と共有し、データだけがここにある。**
コピーしない。`WORKBOOK_DIR` でどの `content.py` を読むかが切り替わる。
関連: `scripts/eng_kokkoritsu_nankan/`（難関編）、`scripts/eng_chuken_kokkoritsu/`（中堅編）。

## ファイル

| | |
|---|---|
| `content_p1/p2/p3.py` | 各部の設問データ。**`assemble.py` が生成する**（手で直してもよい） |
| `content.py` | 3部を統合。`Q_FIELDS`＝問題編に印字してよいフィールド。巻頭の表・手順も持つ |
| `assemble.py` | 作問JSON（大問ごと）→ `content_pN.py`。大問の枠（配点・指示文）の唯一のソース |

```bash
python3 scripts/chugaku2_eigo_soufukushu/assemble.py <作問JSONのディレクトリ>
```

12単元 = 過去形／過去進行形／未来表現／助動詞／接続詞／There is・are／to＋原形／
-ing 形が名詞のはたらき／〈動詞＋人＋物〉と〈動詞＋O＋C〉／比較／受け身／
It is ... to ～・疑問詞＋to ～・〈人＋to ～〉。

## 設計上の約束

- **1問1スロット**。作問前に「どの単元の、どの狙いを問う問題か」を108問ぶん決めてから
  作らせる。決めずに作らせると、同じ部の中で同じルールを何度も問う冊子になる
  （`check.py` の G15 が類似度 0.62 で FAIL にする）。
- **大問ごとに語彙テーマを割り当てる**（学校生活／家族／部活／天気…）。
  これをしないと `played soccer yesterday` のような3語のかたまりが別の大問と重なり、
  「答えを埋めた形が他の設問の問題文に印字されている」（G17）で落ちる。
- **部扉・大問見出し・前書きに文法項目名を書かない**。書けばその大問は解けてしまう。
  単元の一覧・変化表・手順は **解答解説編の巻頭「基本の確認」** に置く
  （`BOOK["tables"]` / `BOOK["flows"]`。問題編には出ない）。
- **各部100点満点**。配点・指示文は `assemble.py` が持ち、作問側には書かせない。
- 英文和訳は要素1つ2点、和文英訳は要素1つ1点（前書きの規定と G16 で機械照合）。
- **中3以降の文法を混ぜない**。現在完了・関係代名詞・分詞の後置修飾・間接疑問文・
  仮定法・so 〜 that・too 〜 to は範囲外。
