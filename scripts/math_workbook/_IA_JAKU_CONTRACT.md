## 0. 絶対に守る5点（違反はゲートで落ちる）

1. **`chk` は答えを「独立に再計算」する**。`(1+2==3)` のようなトートロジー、
   解説に書いた式をそのまま打ち直しただけのものは不可。sympy の `solve`/`simplify`、
   全列挙、実際のシミュレーション等で**別ルートから**答えに到達し、それを答えと照合する。
   例: 因数分解なら `sp.factor(expr) == 想定` ではなく `sp.expand(想定) == expr` と展開側から検算する。
2. **日本語を `$...$` の中に入れない**。KaTeX が斜体英字にする。地の文は素の日本語、数式だけ `$`。
3. **解説は必ず `r"""..."""` (raw string)**。`\neq` `\ne` `\n` 始まりの LaTeX コマンドが
   改行に化けて壊れるため。`\n` を書きたい場面は無い（実改行をそのまま書けばよい）。
4. **`\dfrac` は解説本文で使わない → `\frac` を使う**。組分数の高さが行送りを超え、
   上の行の分母と下の行の分子が物理的に重なる（実際に紙で起きた）。`stem` と `answer` は `\dfrac` 可。
5. **問題編に答えを漏らさない**。`group`（■見出し）は**問題編にも印刷される**ので、
   見出しに答え・結論の語を書かない。同一単元の後の問題文が前の問題の答えを与件にしない。

## 2. 図（SVG）
図が理解に必要な問題（2次関数のグラフ・三角形・円・箱ひげ図など）は `figure` を付ける。

- **`scripts/math_workbook/svgfig.py` の `Canvas` を使って実際の点を計算して描く**。
  手打ち SVG は y の上下と縮尺を必ず間違える（SVG の y は下向き）。
- `Canvas(xr=(xmin,xmax), yr=(ymin,ymax), size=(W,H))` → `.axes() .poly() .circle() .seg()
  .line_abc() .dot() .label() .right_angle() .svg()`。
- ★**`size` は紙の大きさではない**。既定では CSS の `.fig svg{max-height:44mm}` が効くので
  実効スケールは `44mm/H`、つまり **`size` を大きくするほど図は小さく印刷される**。
  縦長の図ほど強く潰れ、`font-size=10` の軸ラベルまで道連れになる
  （A14 の散布図が `H=190` で 6.0pt・幅 29mm まで落ちた。`H=125` の箱ひげ図は 9.0pt）。
  紙の寸法を自分で決めるときは **`.svg(w_mm=55.4)`** を使う（高さは縦横比から自動、
  CSS の上限も inline style で外れる）。字の大きさを他の図と揃えたいなら
  `軸ラベルpt = 10 × (w_mm×2.8346/W) × 0.906`（0.906 = Chrome が文書全体にかける縮小）。
- ★**ラベルが紙で 8pt を割ったら `unit_check_ia_jaku.py` が落とす**（本文は 9.7pt、
  他の図は 8.0〜11.3pt）。落ちたら「作図を小さくする」のではなく **`w_mm=` を渡す**こと。
  そうすれば作図とラベルが同じ倍率で拡大され、数値検算済みのラベル位置がそのまま生きる。
  実際に A17-8 が 6.40pt・A06 が 6.46pt のまま出荷された（`size` を紙の寸法だと思い込むため、
  目で見ても気づけない）。
- 生成した SVG 文字列を `figure` に入れる（ビルダーは esc しない）。
- **`<script>` と `on*` 属性は禁止**。
- **図に本文（stem）に無い数値を書かない**。図が根拠になると設問が本文外に出る。
- ★**答えになる長さ・比を図の上で正確に描かない**。数値を書かなくても、
  与件どおりに作図すると**定規を当てるだけで答えが出る**（実測で誤差 0.1% だった）。
  位置関係だけ正しく描き、答えになる量はわざとずらす。ずらし方と、
  「与件のどれを物差しにしても答えが読めない」ことの機械検算は
  `parts_ia_jaku/A17.py` の `_fig_ratio_audit()` が実例（import 時に assert する）。
  ★検算は**作図と同じ関数から座標をもらう**こと。検査用に座標を書き写すと、
  片方だけ直したときに検査が通ってしまう。
- ✓/✗ は文字で置かず線で描く（PDF で豆腐になる）。
- 図は**問題編にのみ**出る（解説側では stem を再掲しない）。

## 3. 記号の流儀（数学の教材なのでこれに合わせる）
- 不等号は日本式 `\leqq` `\geqq`（`\leq` ではない）。
- 順列・組合せは `{}_{5}\mathrm{P}_{3}` `{}_{7}\mathrm{C}_{3}`。
- 点・図形名はローマン体 `\mathrm{A}` `\triangle\mathrm{ABC}` `\angle\mathrm{A}`。
- 度は `90^\circ`（`\,^\circ` は KaTeX が落ちる）。
- 三角比は `\sin\theta`（`sin` と素で書かない）。
- 絶対値は `|x|`、ベクトルは使わない（この本は I·A）。
- 「かつ」「または」は日本語で書く。
