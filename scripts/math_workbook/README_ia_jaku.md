## 直したら回すもの（順番が大事）

```bash
cd ~/ai-juku-system/scripts/math_workbook

# 4) 総点検（PDF を読む検査を含む。刷った後に回す）
```

`2` を飛ばすと `ia_jaku_gate.py` のゲート3（ドリフト）と `analyze_ia_jaku.py` が
**止まって教えてくれる**（黙って古いタグで診断することはない）。

## 生徒に渡す前後の運用

1. 生徒に **問題集PDF** と **自己採点シート** を渡す（診断キーは渡さない）。
2. 生徒がシートに `○`（自力正解）/ `△`（公式や解説を見て正解）/ `×`（誤り）を書く。解いていない問題は**空欄のまま**。
3. シートの写真から番号を拾って:

```bash
python3 analyze_ia_jaku.py --name 生徒名 --save --skip A18 --hint "A11-2" A06-3 A07-1
```

4. 弱点スキル → つまずきの根っこ → 復習処方（問題番号つき）が出る。`--save` で Desktop に保存。
5. 生徒への声かけは「まず○○番をもう一回」だけ。**弱点タグ名は口にしない**。

★番号は **`A07-3` の形（接頭辞 A 必須）**。数字だけの `07-3` はエラーにしてある
（第1集=01〜12 / 第2集=13〜27 / 化学=C01〜C18 と番号が衝突し、貼り間違えても検出できなくなるため）。

## 踏んだ罠（同じ穴を掘り直さないために）

- **診断キーの表で `<br>` がリテラル印字された**（56箇所）。`esc()` しただけだと
  `&lt;br&gt;` になり紙に `"<br>"` と出る。表示用の `stem_html()` を通すこと。
- **`stamp_pdf` は最後に `subset_fonts()` でフォントを削る**。その後に `insert_text` すると
  字が埋め込まれておらず柱が丸ごと `\x00` になる。**刻印は subset より先**。
- **図の `size` は紙の寸法ではない**。CSS の `max-height:44mm` が実効スケールを決めるので、
  `size` を大きくするほど紙では縮む（ラベルが 6.4pt まで落ちた）。**`w_mm=` を渡す**。
- **図を答えどおりの実寸で描くと定規で答えが読める**。`A17._fig_ratio_audit()` が
  import 時に「図の実測比が答えに近すぎないか」を強制する。図を足したら audit の対象にも足す。
- **`__pycache__` の罠**: 同じ長さの置換は mtime秒＋サイズが一致して旧 `.pyc` が使われ、
  「直したのに反映されない」「変異させたのに chk が True」が起きる。`python3 -B` か `touch` で切り分ける。
- **KaTeX の行箱は vlist の height:0** なので、残り2ptしか無い行にも1行入ると判定され、
  版面外に 2pt の切れ端が出る（中身は次ページに完全に出るので欠落はしない）。

## 診断の設計（`analyze_ia_jaku.py`）

- スコア = 誤答重み ÷ 全体重み。`LEVEL_W` は **基礎1.5 / 標準1.0 / 発展0.6**（基礎ミスほど重い）、
  `ROLE_W` は 主1.0 / 副0.4。`△` は重み 0.5 の誤答として算入する。
- 弱点断定には **誤答2問以上**の証拠を要求（1問なら「要再測」）。
- ★**2つ目の入口 `UP_TH`**: 基礎重み1.5のせいで「基礎は取れるが標準以上は全滅」の生徒が
  13スキルで素通りしていた。**標準以上だけのスコア**でも判定する。
- ★**主スキルとしての誤答が1問も無いスキルは、どちらの経路でも弱点にしない**。
  副担当が多いスキル（DA3/TR3/CP2/CP4/TR4/IN5）が、主担当を全問正解していても
  「根っこ」と断定され処方の先頭に来ていた。
- ★**根っこの探索は `weak ∪ watch` を辿る**。weak だけだと前提が[要注意]止まりのとき連鎖が切れ、
  平方完成を8問落としている生徒に「根っこは最大最小」と報告していた。

## 既知の限界（塾長判断が要るもの）

- **■見出しが解法を名指ししている群がある**（A11「角と向かい合う辺が分かっているとき」＝正弦定理 など）。
  第2集からの様式だが、「正弦定理と余弦定理のどちらを使うか」を測りたい場合は
  A17 の「チェバとメネラウスの使い分け」のような**仕分け用の群**を足す必要がある。
- **編扉の「攻略の手順」は公式そのもの**を渡している。同じ見開きに問題が来る編があるので、
  ボックスに「見ながら解いたら △」と明記してある。○/△ の記録が診断の精度そのものになる。
