スタディサプリ「高3 古文〈文法編〉」全12講の**単元の並びに1対1で対応**させた演習プリント。

## 著作権の線引き（★これを崩さない）

講義テキストは有料配信の著作物で、冒頭に無断複製・転載禁止の表示がある。
**複製してよいのは何も無い。** この冊子が講義に対応しているのは

- 各講が扱う**文法項目とその順番**（＝事実。目次レベルの情報）
- 各講が使っている**覚え方の語呂**（スイカかえて／スイカとめて／衣・食・乗 など。
  いずれも広く使われている一般的な暗記法で、講義固有の表現ではない）

だけ。例文・解説・現代語訳・図表はすべてこちらで新規に書いている。
対応表に講座名を出しているのは、生徒が「第○講を見たら第○部」と分かるようにするための
事実の参照。前書きに「講義テキストを写したものではない」と明記してある。

## データの持ち方

設問は `data/L01.json` 〜 `L12.json`（1講1ファイル）。**Python に直書きしない。**
12講×13問を並列で書かせると、Python 直書きでは1箇所の構文エラーで全体が import できず
原因の場所も分からなくなる。JSON なら壊れたファイルだけが落ちる。

`ingest.py` が `check.py` の前段。層を分けているのは、構造が崩れていると `check.py` が
無関係な場所で落ちて原因が読めないため。

- `ingest.py` … JSON が仕様どおりか（大問の形・配点・`ans` の範囲・`exp` の字数・傍線の対応）
- `check.py` … 冊子として成立しているか（解答漏洩・重複・採点規定の一致など約20ゲート）

## ★正解位置を均すときの例外

`ingest.py --balance` は四択の正解位置を md5 順で散らすが、
**「未然形・連用形・終止形・連体形」のように順序が決まっている選択肢群は並べ替えない**。
活用形や活用の種類は教科書どおりの順で刷るのが普通で、
バラバラに並べると教材として不自然になる。`CANON` に列挙してある。
この場合の正解位置は文法の側で決まるので、著者の偏りにはならない。

## 表は問題編に載せない

活用表・接続表・助詞一覧・敬語一覧は**解答解説編の巻頭にだけ**置く。
問題編に置くと、接続や活用を問う設問が表を写すだけで解けてしまう。

表の実体は `scripts/_kobun_tables.py`（助動詞ドリル `scripts/kobun_jodoushi` と共有）。
**ここにコピーを作らないこと。** 片方だけ直って冊子間で矛盾する。

## 検証の層（どれも別のものを見ている）

1. `ingest.py` … 構造
2. `check.py` … 冊子としての成立
3. `blind.py` … 3独立盲ソルバーが解く → Python が鍵と照合（全員が鍵と違う＝鍵の誤り）
4. **辞書による事実検証** … 解説の文法的主張が正しいか。★古文ではこの層が必須。
   盲ソルバーは「鍵が正しいか」しか測らないので、解説の文法説明の誤りは通り抜ける。
