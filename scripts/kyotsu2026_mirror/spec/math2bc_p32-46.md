- **(2)** 「z が C 上を動くとき，w が複素数平面上で描く図形を考える。実数 θ を z の偏角とし，極形式を用いて z = r(cosθ + i sinθ) と表す。」
  - **(i)** 「w = z + 1/z を r, θ を用いて表すと w = [キ] + i [ク] ……① である。したがって，θ の値によらず [ク] = 0 となるような r の値は [ケ] である。」

    - ケ=数値1桁(一重枠)。参考解: キ⑥, ク⑨, ケ=1。
  - **(ii)** (p41) 「r = [ケ] とする。z が C 上を動くとき，w が描く図形は [コ] である。」— 既出ケを一重枠で再掲。
    - 指示文: 「[コ] については，最も適当なものを，次の⓪〜⑤のうちから一つ選べ。」
    - **コ = 図6択** (2列×3段、各図は x-y 座標軸+O):

  - **(i)** 「w² を z を用いて表すと，w² = [シ] である。」
    - **シの解答群** 6択(3列×2行): ⓪ z²+1/z² ① z²+1/z²+1 ② z²+1/z²−1 ③ z²+1/z²+2 ④ z²+1/z²−2 ⑤ z²+1/z²+2i  — 定数項 {0, ±1, ±2, 2i} のバリエーション。参考解: シ=③。
  - **(ii)** 「z が C 上を動くとき，z²+1/z² が描く図形の方程式を考える。このとき，**z² は原点Oを中心とする半径 r² の円を描く**。このことから，X, Y を実数として z²+1/z² = X+Yi とおくと，X, Y は [ス] を満たす。以上を踏まえると，w² が描く図形は [セ] であることがわかる。」— 核となる事実(z²の軌跡)は問題文が与える。
    - **スの解答群** 6択(縦1列): ⓪ X/(r²+1/r²) + Y/(r²−1/r²) = 1 (1乗の直線型) ① X²/r⁴ + Y²/r⁴ = 1 ② X²/(r²+1/r²)² + Y²/(r²−1/r²)² = 1 ③ X²/(r²+1/r²)² − Y²/(r²−1/r²)² = 1 ④ X²/(r²−1/r²)² + Y²/(r²+1/r²)² = 1 ⑤ X²/(r²−1/r²)² − Y²/(r²+1/r²)² = 1  — サと同型の系統だが r→r² 化+1乗型distractorを追加。参考解: ス=②。
  - **セ** (p45、最終ページ): 指示文「[セ] については，最も適当なものを，次の⓪〜⑦のうちから一つ選べ。」
    - **図8択** (2列×4段、各図 x-y 軸+O、楕円の中心に破線の軸線と中心x座標の数値ラベル):
      - ⓪ 縦長楕円・中心(−2, 0) ① 縦長楕円・中心(2, 0)
      - ② 横長楕円・中心(−2, 0) ③ 横長楕円・中心(2, 0)  (②③は原点をまたぐ大きさ)
      - ④ 小さめ横長楕円・中心(−2, 0) ⑤ 小さめ横長楕円・中心(2, 0)
      - ⑥ 縦長楕円・中心O・x切片±1・y切片±2 (目盛 −1,1,2,−2 明記)
      - ⑦ 横長楕円・中心O・x切片±2・y切片±1
    - distractor軸: 中心(±2/原点) × 向き(縦長/横長) × 大きさ(大/小)。参考解: セ=③ (スの楕円を実軸方向に+2平行移動)。
    - 最終ページは選択肢図のみで終了。「続く」注記・終了宣言なし。フッター「— 45 —」「(2104—45)」。

## 4. 紙面共通仕様 (範囲内で観測されたもの)

1. **空欄枠の使い分け**: 数字を直接マークする空欄=**一重線の四角**(カタカナ1文字=1マーク桁)。解答群・図から選ぶ空欄=**二重線の四角**。既出空欄の再掲は元と同じ枠種で本文中に埋め込む。
2. **分数・根号スロット**: 分数は枠を縦に重ね横棒(例 [オ]/[カ])、根号複合は「[イ]√[ウ]/[エ]」のように係数枠+√内枠。
3. **解答群の見出し2型**:
   - 通常: 「[X] の解答群」/共用時「[X]，[Y] の解答群(同じものを繰り返し選んでもよい。)」「[エ]〜[ケ]の解答群(…)」
   - 値・図選択: 「[X] については，最も適当なものを，次の⓪〜⑦のうちから一つ選べ。」
4. **選択肢**: 丸数字⓪①②…(0始まり)。矩形枠で囲んだ解答群ボックスに1〜3列で配置。図選択肢は枠なしで2列グリッド+左上に丸数字。
5. **式番号**: 中央寄せ数式の右端に「……… ①」(点線リーダー+丸数字)。後続参照は「①から」「②を満たす」。
6. **会話ボックス**: 破線の矩形枠、「太郎:」「花子:」で始まる行、2行目以降は字下げ。
7. **選択問題の注意書き**: 黒実線枠1行「第4問〜第7問は，いずれか3問を選択し，解答しなさい。」を**選択大問の開始ページ上部に毎回**置く。見出しは「第N問 (選択問題) (配点 16)」。
8. **ページ送り注記**: 大問継続時は各ページ右下に「(数学Ⅱ，数学B，数学C第N問は次ページに続く。)」。間に下書き用紙等を挟む場合は「…第6問は36ページに続く。」とページ番号指名。
9. **下書き用紙ページ**: 「(下 書 き 用 紙)」中央+「数学Ⅱ，数学B，数学Cの試験問題は次に続く。」。見開き調整用に大問の小問間にも挿入される(p35は第6問(1)と(2)の間)。
10. **フッター**: 中央「— NN —」、右下「(2104—NN)」。
11. **組版の余白許容**: 解答群や図選択肢セットを1ページに収めるため、本文ページ下部に大きな余白を残す(p42が典型: 本文4行+続く注記のみ)。
12. **図**: 黒丸点+英大文字ラベル、キャプション「図 1」「参考図」を図の直下中央。統計の分布曲線図は塗り(グレー)で面積を示す。

## 5. 類似問題を作るためのパラメータ化レシピ

### 5-1. 第5問型 (母比率の仮説検定・後半部分)

パラメータ: 帰無仮説の母比率 p₀ (p₀(1−p₀) がきれいな値: 0.4→0.24, 0.2→0.16, 0.5→0.25)、大標本 n₁ (σ₁=√(p₀(1−p₀)/n₁) が「√k/整数」になるよう選ぶ; 実物は n₁=400→σ=√6/100)、小標本 n₂=100、共通の標本比率 p̂。
制約: z₁=(p̂−p₀)/σ₁ が棄却域内(片側5%なら>1.64、実物は≈2.45)、z₂=(p̂−p₀)/σ₂ が棄却域外(実物≈1.22)。√近似値(√6=2.45等)を本文で指定し、z値が正規分布表の行×列にちょうど乗ること(1.22→0.3888、2.45→0.4929)を機械検証する。
- 生成手順: ①p₀, p̂, n₁, n₂ を決める → ②σ, z, 表値, 裾確率を厳密計算 → ③キ型8択は {正解裾確率, その表値, もう一方の標本の対応ペア, 隣接z(±0.05〜0.15)の混同値} で構成 → ④ク(2×2文)・コ(2択)・サ(2択)・ケ(2択判断文)は固定文言を流用 → ⑤(3)は「同じ比率でも n が小さいと棄却されない」構図を守る。
- 正規分布表は §1-3 の体裁で毎回同一(値は標準のもの)。第5問の最終ページ直後に置き、直前ページに「次ページに続く」を入れる。

### 5-2. 第6問型 (始点Mの一次結合とPの不変条件・存在範囲)

核構造: MP→ = aMA→ + bMB→ + cMC→ で「Pの位置がMに依存しない ⇔ 係数和=1」を誘導し、a+b+c=1 上で追加制約により存在範囲(直線/半平面)を問う。
- (1)パラメータ: 具体係数 (a,b,c)=(1,2,−1) 相当の整数組(和≠1でも可、答が図の頂点に着地することが条件)。図は「正六角形+中心」など、単位ベクトルの整数結合で全候補点が読める配置。M の取り方2通り(頂点/外点)で P が別の点になるようにする。解答群=図中の点ラベル7択・繰返し可。
- (2): A始点への書換え誘導は固定パターン。ウ=±AP±AM の4択、エ〜ケ=係数10択(単変数 a,b,c / 符号組合せ4種 / 1±(a+b+c) 2種)、コ=条件9択(対等式3+混合等式3+和=定数3)。**正解列 (エ,オ,カ)=(b,c,−a−b−c)、(キ,ク,ケ)=(b,c,1−a−b−c)、コ=a+b+c=1** の構造を保ったまま文字名・符号の見せ方を変える。
- (3)(i)パラメータ: 固定する変数と値 (実物: a=1/2)。答は「中点連結線」(a=t なら BC を A中心に比 t で縮めた直線)。解答群は {頂点–対辺中点線3, 中点連結線3} の6択固定。参考図(三角形+3中点)を添える。
- (3)(ii)パラメータ: 不等式制約 (実物: c<0)。答=「直線ABのC反対側の開半平面」。6図の塗り分けセットは {三角形のみ / 1頂点の内角領域 / 三角形+対頂角 / 正解半平面 / 半平面∩上側半平面 / 反対側半平面} を流用し、どの頂点・どの符号かでバリエーション生成。「ただし，境界線を含まない。」を必ず付す。
- 会話(花子・太郎)は「具体例の観察→一般化の問い」の橋渡しに置く。

### 5-3. 第7問型 (w = z + k/z の像)

核構造: ジューコフスキー変換。円 |z|=r の像が楕円(退化して線分)、さらに w² で「平行移動された楕円」。
- パラメータ: ①具体値 z₀ (|z₀| が整数になる √a+bi 型; 実物 √3+i→|z|=2、1/z₀ が簡単に有理化できること) ②円の半径 r (文字のまま) ③退化半径 (k=1なら r=1) ④シフト定数 (w²=z²+1/z²+2 の「+2」)。変形: w=z+a²/z (軸 r±a²/r)、w=z−1/z (虚軸線分に退化)。
- 空欄設計: (1)は数値マーク(絶対値1桁+実部「n√m/d」+虚部「p/q」)。(2)(i)は cos/sin 対の10択(係数 2r, r±1, r±1/r)+退化rの数値。(ii)は図6択 {実軸線分±1/±2, 虚軸線分±1/±2, 山型曲線 高さ1/2}。(iii)はθ消去→2次曲線6択 {x²/r²±y²/r², x²/(r+1/r)²±y²/(r−1/r)², 分母入替型}。
- (3)は w² 展開の定数項6択 {0,±1,±2,2i} → 「z²は半径r²の円」を本文で与えて (ii)の楕円方程式6択(r→r²版+1乗直線型distractor) → 平行移動後の図8択 {中心±2/原点 × 縦長/横長 × 大/小}。
- 機械検証項目: 展開の定数項、楕円半軸 r+1/r>|r−1/r| (→横長)、シフト方向(実軸正)、図ラベルの整合。

### 5-4. 選択肢設計の通則 (観測ベース)

- 数式解答群は「符号・入替の全組合せ」を系統的に並べる(ウ4択=±±、サ6択=楕円/双曲線×分母入替)。
- 図選択群は「正解+1軸ずつ狂わせた変種」(向き・中心・大きさ・範囲の直積から6〜8個)。
- 値選択群は「正解と 0.5−正解 のペア+隣接パラメータの値ペア」。
- 複数空欄で1つの解答群を共有するときは必ず「(同じものを繰り返し選んでもよい。)」。
- 選択肢数の実測: 2択(コ・サ・ケ@第5問)、4択(ク・ウ)、6択(カ・サ@6問・シ・コ@7問・サ@7問・シ@7問(3)・ス)、7択(ア・イ@6問)、8択(オ・キ@5問・セ)、9択(コ@6問)、10択(エ〜ケ@6問・キク@7問)。
