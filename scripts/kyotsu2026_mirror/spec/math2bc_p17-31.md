# 第3問(必答問題)(配点 22) — 微分法・積分法(数学Ⅱ)

- 冊子16〜21ページ(PDF 17〜22)。純数学設定(会話文・日常文脈なし)。(2)のみ「〜考えよう。」の呼びかけ調。
- 大問は (1)(2) の2部構成。(1)は1つの3次関数の解析(微分→グラフ概形→積分条件)、(2)は概形の論理判定(条件を満たすグラフの選別)。

## (1) 3次関数 f(x) = (1/3)x³ − 2x² + 3x + k(k は実数)

### (i) 導関数と極値 — 空欄 ア〜オ
- 「f′(x) = [ア] である。」 — **ア = 選択式(二重枠)・6択**
  - アの解答群: ⓪ (1/3)x²−2x+3 ① (1/3)x²−2x+3+k ② x²−4x+3 ③ x²−4x+3+k ④ (1/12)x⁴−(2/3)x³+(3/2)x²+kx ⑤ (1/3)x⁴−2x³+3x²+kx
  - 誤答肢の設計: 係数を1/3のまま微分し忘れ(⓪①)、+k を残す(①③)、微分でなく積分(④⑤)。正解は ②。
- 「x = [イ] のとき,f(x)は極大値 [ウ] をとる。」「x = [エ] のとき,f(x)は極小値 [オ] をとる。」
  - **イ・エ = 数値マーク(一重枠)各1桁**(イ=1, エ=3)
  - **ウ・オ = 選択式(二重枠)・10択共通解答群(繰り返し選択可)**
  - ウ,オの解答群: ⓪ 0 ① 1 ② 2 ③ 2/3 ④ 4/3 ⑤ k ⑥ −4/3+k ⑦ −2/3+k ⑧ 2/3+k ⑨ 4/3+k(ウ=⑨ 4/3+k, オ=⑤ k)
  - 数値5個+kを含む式5個の混成群。極値が定数kを含むため選択式にしてある点が構造上の特徴。

### (ii) グラフの概形 — 空欄 カ・キ(図選択)
- 「y=f(x)のグラフの概形は k=0 のとき[カ]/ k>0 のとき[キ] である。」— **カ・キ = 選択式・6択(繰り返し可)**
- 選択肢は次ページ(冊子17)に**3次関数グラフの概形図6個(⓪〜⑤、2列×3行)**。指示文「[カ],[キ]については,最も適当なものを,次の⓪〜⑤のうちから一つずつ選べ。ただし,同じものを繰り返し選んでもよい。」
- 6図の設計(すべて極値2個 or 接触型、座標軸とOのみ・目盛りなし):
  - ⓪ 正係数・極大も極小も x軸より上(y切片>0)
  - ① 負係数・⓪の鏡像(両極値が x軸より上、右端で x軸を下抜け)
  - ② 正係数・原点を通り、**極小が x軸に接する**(y切片=0)
  - ③ 負係数・②の鏡像(極小が x軸に接し、y切片>0)
  - ④ 正係数・**極大が x軸に接する**・極小は x軸より下
  - ⑤ 負係数・④の鏡像(原点を通り、極大が x軸に接する)
  - 対になる設計: {正/負係数} × {極小接地(k=0型)/両極値上方(k>0型)/極大接地(k<0型)} の 2×3=6。正解: カ=②, キ=⓪(f の極小値=k, 極大値=4/3+k から判定)。
- ページ末に続行注記「(数学Ⅱ,数学B,数学C第3問は次ページに続く。)」

### (iii) 積分(面積等分条件)— 空欄 ク〜セソ(冊子18〜19 / PDF 19〜20)
- 設定文(要約): (i)のイ・エのうち小さい方を α とする。f(0)<0<f(α) を満たす k の範囲は **[ク] < k < [ケ]**。この範囲で 0≦x≦α における f(x)=0 の解を β とおき、「0≦x≦β の y=f(x) と x軸・y軸で囲まれた面積」=「β≦x≦α の y=f(x) と x軸・直線 x=α で囲まれた面積」とする。
- 「このとき,[コ] が成り立つ。したがって,k = [サシス]/[セソ] である。」
- **ク・ケ = 選択式・10択共通(繰り返し可)**(冊子19に解答群): ⓪ 0 ① 2/3 ② 3/4 ③ 4/3 ④ 3/2 ⑤ 5/2 ⑥ −2/3 ⑦ −3/4 ⑧ −4/3 ⑨ −3/2(正: ク=⑧ −4/3, ケ=⓪ 0)。正値5個(⓪〜⑤... 正確には0と正4個+5/2)と負値4個の対称構成。
- **コ = 選択式・4択**(積分等式の同値言い換え):
  - ⓪ ∫₀^β f(x)dx = ∫_β^α f(x)dx ① ∫₀^α f(x)dx = 0 ② ∫₀^β f(x)dx = 0 ③ ∫_β^α f(x)dx = 0
  - 正解 ①(面積相殺 ⇔ 全区間の定積分が0)。「面積が等しい⇔積分=0」の概念理解を4択で問う型。
- **サシス・セソ = 数値マーク(一重枠)の分数**: k = [サシス]/[セソ]。分子3桁枠・分母2桁枠。**負号がマーク1桁を占有する**(正: −11/12 → サ=−, シス=11, セソ=12)。

## (2) 条件からグラフ概形を絞り込む問題(冊子20〜21 / PDF 21〜22)
- リード文: 「3次関数 g(x) に対して,与えられた条件のもとで y=g(x) のグラフの概形を考えよう。」
- 3段の**条件追加型・絞り込み構造**(箇条書き「・」で条件ブロックを積む):
  - **条件(a)** g(0)=0 かつ g′(0)>0。→「後の⓪〜⑦のうち,条件(a)を満たす…概形は [タ],[チ],[ツ] の三つであり,残りの五つは条件(a)を満たさない。ただし,[タ],[チ],[ツ] の解答の順序は問わない。」(**8択から3つ・順不同**)
  - **条件(b)**((a)に追加)y=g′(x) のグラフは直線 x=0 を軸とする放物線である。→ 満たすのは [テ],[ト] の二つ(**8択から2つ・順不同**)。「残りの六つは条件(a),(b)の少なくとも一方を満たさない。」
  - **条件(c)**((a)(b)に追加)y=g′(x) のグラフは下に凸の放物線である。→ 満たすのは [ナ] の一つだけ(**8択から1つ**)。
- 選択肢図は次ページ(冊子21)に**グラフ概形8個(⓪〜⑦、2列×4行)**。指示文「[タ]〜[ナ]については,最も適当なものを,次の⓪〜⑦のうちから一つずつ選べ。ただし,同じものを繰り返し選んでもよい。」
- 8図の設計(座標軸とOのみ):
  - ⓪ 正係数・原点を通り**原点で減少**(極大は左上方・極小は右下方、原点対称形)
  - ① 負係数・原点を通り**原点で増加**(極小は左下方・極大は右上方、原点対称形)= ⓪の鏡像
  - ② 正係数・**両極値とも y軸の左**・原点を最終上昇枝で通過(g′(0)>0)
  - ③ 負係数・両極値とも y軸の左・原点を最終下降枝で通過(g′(0)<0)= ②の鏡像
  - ④ **単調増加**(y=x³型・極値なし)・原点通過
  - ⑤ **単調減少**(y=−x³型)・原点通過 = ④の鏡像
  - ⑥ 正係数・両極値が y軸の左・**y軸を正の値で横切る(g(0)>0, 原点不通過)**
  - ⑦ 負係数・極小左下方/極大が y軸近くの上方・y軸を正の値で横切る(g(0)>0)= ⑥の対
  - 設計論理: (a)の判定軸=「原点を通るか(g(0)=0)」×「原点での傾き符号」、(b)=「変曲点が y軸上(=原点対称)か」、(c)=「係数の正負」。正解: タチツ={①,②,④}(順不同), テト={①,④}, ナ=④。
- 正/負係数のペア(⓪①、②③、④⑤、⑥⑦)で並べる構成。

# 第4問(選択問題)(配点 16) — 数列(数学B) 冊子22〜26(PDF 23〜27)

- 題材: **階差数列**。前文で定義を明示提示してから使う体裁:
  「数列{aₙ}に対して **bₙ = aₙ₊₁ − aₙ (n = 1, 2, 3, …)** で定められる数列{bₙ}を,{aₙ}の**階差数列**という。」
- (2)(3)は**太郎さん/花子さんの登場する探究型**(会話文ではなく「太郎さんは…考えた」の地の文)。**「発想」ボックス**(角丸罫囲み・見出し「発想」を枠線上に重ねる)が核: 「ある数列{dₙ}の和を求めたいときは,数列{cₙ}で,{cₙ}の階差数列が{dₙ}となるものを見つければよい。」

## (1) 基本計算(bₙ = 4n−1, a₁ = 1)
- (i) 「b₁ = [ア] であるから,a₂ = [イ] となる。さらに,b₂ = [ウ] であるから,a₃ = [エオ] となる。」
  - **ア・イ・ウ = 1桁数値、エオ = 2桁数値**(すべて一重枠。正: 3, 4, 7, 11)
- (ii) 「n を2以上の自然数とする。このとき aₙ = a₁ + Σ_{k=1}^{[カ]} b_k …①」
  - **カ = 選択式・4択**: ⓪ n−1 ① n ② n+1 ③ n+2(正: ⓪)
  - **特徴的組版: 二重枠の選択スロット[カ]が Σ 記号の上端(上限)に埋め込まれる**
  - 「が成り立つことから aₙ = [キ] n² − [ク] n + [ケ] であることがわかる。」— **キクケ = 1桁数値**(符号・形は式に印字済み。正: 2, 3, 2 → aₙ = 2n²−3n+2)

## (2) 太郎さん: dₙ = (2n+1)·2ⁿ の和(冊子24〜25)
- 導入: 「①を変形すると Σ_{k=1}^{[カ]} b_k = aₙ − a₁ となることから」(既出スロット[カ]を再掲表示)→ 発想ボックス。
- {cₙ}の一般項を **cₙ = (pn+q)·2ⁿ**(p, q は定数)と推測し、
  「cₙ₊₁ − cₙ = {[コ] n + [サ]}·2ⁿ となる。」
  - **コ・サ = 選択式・8択共通(繰り返し可)**: ⓪ p ① q ② 2p ③ 2q ④ (p+q) ⑤ (2p+q) ⑥ (p+2q) ⑦ 2(p+q)(正: コ=⓪ p, サ=⑤ 2p+q)
  - 文字定数 p,q の1次結合を網羅した選択肢群(対称に 2倍・和・混合を配置)
- 「よって,p = [シ], q = [スセ] のとき②が成り立つ。」— **シ = 1桁数値(2)、スセ = 2桁枠で負号込み(−3)**
- ページをまたいで(冊子25)結論: 「以上のことから,すべての自然数 n について,数列{dₙ}の初項から第 n 項までの和は **Σ_{k=1}^{n} d_k = ([ソ])·2^{n+1} + [タ]** となることがわかる。」
  - **ソ = 選択式・6択**: ⓪ n−1 ① n+1 ② 2n−3 ③ 2n−1 ④ 2n+1 ⑤ 2n+3(正: ③ 2n−1)
  - **タ = 1桁数値**(正: 2)。係数部分([ソ])は丸括弧付きで印字される
  - 数学的背景: cₙ=(2n−3)·2ⁿ, Σ = c_{n+1}−c₁

## (3) 花子さん: dₙ = (n²−n−1)·2ⁿ の和(冊子26)
- 「(2)の**発想**に基づいて考えると」(太字「発想」で前段参照)、
  「Σ_{k=1}^{n} d_k = ([チ])·2^{n+1} **−** [ツ] となることがわかる。」((2)は「+[タ]」、(3)は「−[ツ]」と符号が印字で異なる点に注意)
- **チ = 選択式・10択**: ⓪ 3n−3 ① 3n+3 ② 5n−7 ③ 5n+7 ④ n²−n−1 ⑤ n²+n+1 ⑥ n²+3n−3 ⑦ n²−3n+3 ⑧ n²+5n−7 ⑨ n²−5n+7
  - 1次式4個+2次式6個の混成。正: ⑦ n²−3n+3(cₙ=(n²−5n+7)·2ⁿ ← ⑨も選択肢に置いて cₙ と Σ の取り違えを誘う設計)
- **ツ = 1桁数値**(正: 6)
- (3)は解答群含め1ページで完結。(2)の骨組み(推測→係数比較→和)を数値だけ2次に上げて反復させる「型の転移」問題。

# 第5問(選択問題)(配点 16) — 統計的な推測(数学B) 冊子28〜30(PDF 29〜31)【範囲内は途中まで】

- 冒頭に注意書き(1行・地の文): 「以下の問題を解答するにあたっては,**必要に応じて33ページの正規分布表を用いてもよい**。」→ **正規分布表は冊子33ページ(範囲外)のため体裁未確認**。
- 設定(日常文脈型): ある自治体の「地域の知識を問う**資格試験**」。200点満点、**120点以上で合格**。

## (1) 正規分布の標準化(冊子28)
- 今年の受験者全体: 平均116点・標準偏差25点、得点は正規分布に従う。確率変数 X。「X は正規分布 N(116, 25²) に従うから,**Y = [ア]** とおくと,Y は標準正規分布 N(0, 1) に従う。」
  - **ア = 選択式・6択**: ⓪ (X−116)/5 ① (X−116)/25 ② (X−116)/25² ③ (X−120)/5 ④ (X−120)/25 ⑤ (X−120)/25²(正: ①)
  - 誤答設計: 分母{5(=√25), 25, 25²} × 分子{−平均116, −合格点120} の 2×3 マトリクス
- 「今年の受験者全体のうち,120点以上である受験者の割合 **P(X≧120) はおよそ [イ]** である。」
  - **イ = 選択式・8択**(数値選択・「最も適当なものを…一つ選べ」): ⓪ 0.16 ① 0.21 ② 0.29 ③ 0.34 ④ 0.41 ⑤ 0.44 ⑥ 0.50 ⑦ 0.84(正: ⑤ 0.44。z=0.16)
  - 誤答に z値そのもの(0.16)、1−答(0.16/0.84 ペア)を混ぜる設計

## (2) 母比率の仮説検定(冊子29〜30)
- 設定: A地域の合格率は過去10年毎年40%(0.4)超。「今年も0.4より高いと判断してよいか」を n 人の無作為抽出で調べる。
- **(i)** ベルヌーイ確率変数の定義: i番目の受験者が合格なら1・不合格なら0の確率変数 Wᵢ(i=1,2,…,n)。母集団は十分大きい、合格率 p。
  - **表1**(Wᵢ の確率分布表・罫線表): 1行目「Wᵢ | 0 1 | 計」、2行目「確率 | 1−p p | 1」。見出し列と本体の間は二重縦罫、「計」列の前は単縦罫。表題「表 1」は表の上中央。
  - 「表1から,Wᵢ の平均(期待値)E(Wᵢ) は [ウ] となる。また,Wᵢ の分散 V(Wᵢ) について **V(Wᵢ) = {0−E(Wᵢ)}²(1−p) + {1−E(Wᵢ)}²p** から,V(Wᵢ) は [エ] となる。」(分散の定義式を本文に印字して計算を誘導)
  - **ウ・エ = 選択式・6択共通(繰り返し可)**: ⓪ p ① 1−p ② p² ③ p(1−p) ④ p²(1−p)² ⑤ p³+(1−p)³(正: ウ=⓪, エ=③)
- **(ii)** 標本平均 W̄ = (W₁+W₂+…+Wₙ)/n。「n が十分に大きいとき,W̄ は近似的に正規分布 **N(p, [オ])** に従う。」(オ=分散スロット。**解答群は範囲外・次ページ**)
  - 仮説検定の用語を本文中で定義する体裁: 「統計的に検証したい仮説を『**対立仮説**』,対立仮説に反する仮定として設けた仮説を『**帰無仮説**』とする。」帰無仮説「p=0.4」・対立仮説「p>0.4」、**有意水準5%(0.05)**。
  - データ: **無作為に選ばれた400人のうち184人が合格**(184/400=0.46)。「標本平均 W̄ は近似的に平均が0.4,標準偏差が **[カ]** の正規分布に従う。」
