## 1. 第3問末尾 (p35〜36) — 実用文・資料比較の残り2設問

※第3問はMさん(生徒)がイワシに関する複数資料(【資料Ⅱ】【資料Ⅲ】=絵本/科学解説系の文章とその図1・図2)を比較して文章を書く、という学習場面設定。本文・資料本体は範囲外。

### (i) 表完成型・誤り選択 (解答番号 20・21)
- 柱書き: 「Mさんは、空欄 X に書く内容の準備として【資料Ⅱ】と【資料Ⅲ】を比較し、それぞれの特徴を次の表にまとめた。**a欄とb欄に書くこととして誤りを含むものを、後の①〜⑥のうちから二つ選べ。ただし、解答の順序は問わない。**」
- 表: 2列ヘッダのみの空表(a=【資料Ⅱ】の特徴 / b=【資料Ⅲ】の特徴)。
- 選択肢①〜⑥: **各選択肢が「a記述+b記述」の2文ペア**(縦書きで右列にa、左列にb。計12文)。誤りを含むペアを2つ選ぶ。
- 記述の観点系統(複製時のネタ帳):
  - ①a 図1で命の危険性を切迫感をともなう形で伝える / ①b 図2で索餌の標準的な場所・捕食方法を視覚的に示す
  - ②a 図1でストーリーの一場面の情景をわかりやすく伝える / ②b 図2で誕生→成長→産卵の動きをおおまかに示す
  - ③a 「ています」「てきます」等の文末で精選情報をリアリティーをもって伝える / ③b 「12〜6月」「秋」の時期明示で時系列に沿って事実を伝える
  - ④a 擬音語・擬態語で生き物の様子を想像しやすくする / ④b 具体的な数値で仔魚の減少を理解しやすくする
  - ⑤a ある群れに起こった出来事を取り上げる方法 / ⑤b 特定の群れに限定しない解説方法
  - ⑥a 情報を限定した短文で厳しさを強調し過ぎない / ⑥b 研究成果・専門知識を詳しく紹介して生存戦略を理解させる

### (ii) 比較結果の分析+今後の方針 (解答番号 22)
- 柱書き: 「Mさんは、【資料Ⅱ】に見られる工夫を考察するため、【資料Ⅱ】と【資料Ⅲ】の比較結果の分析に基づいて、今後の方針を考えている。比較結果の分析と今後の方針の内容として最も適当なものを、次の①〜④のうちから一つ選べ。」
- 選択肢①〜④は全て同一の複文テンプレ:
  「比較した結果、【資料Ⅱ】には、**〔特徴X〕といった、子どもに生き物の世界の魅力を伝えることにつながる複数の特徴がある**ことがわかった。これをふまえ、今後は**〔検討目的Y〕**を検討するために、**さまざまな〔本の種類Z〕を用意して【資料Ⅱ/Ⅲ】と比較する。」

- **問1(語の意味)**: (ア)宗旨→①祖先の教説②党派の主張③深遠な教義④主要な見解/(イ)知言→①見識のある言葉②もっともらしい言葉③よく聞く言葉④自明の言葉。**選択肢は「修飾語+名詞」の短い名詞句4つ**。漢字の字面から連想される誤義を並べる。

- **問3(返り点+書き下し)**: 白文「是雖狭見使然」に対し、**〔返り点パターン+書き下し文〕のペア5組**。書き下しの対立軸=「雖」の係る範囲(狭のみ/狭見まで)×「見」の扱い(動詞「見る」/受身の助字)×「使」の訳(使役「然らしむ」/受身併合「然らしめらる」)。観察された5肢の書き下し:
  ①是れ狭く然らしめらると雖も/②是れ狭見の然らしむと雖も/③是れ狭しと雖も見て然らしむるは/④是れ狭しと雖も然らしめらるるは/⑤是れ狭見と雖も然らしむるは(各肢に整合する返り点を併記)。
- **問4(解釈・句形)**: C「不亦已駭乎」=「不亦〜乎」の詠嘆形+注6(駭=愚かなさま)。選択肢は文末表現だけ変える: ①やはり愚かなことであろうか。②どうして愚かなことだといえようか。③なんと愚かなことであろうか。④かえって愚かだといえようか。**句形の型訳(なんと〜ではないか)を知っているかの一点勝負**。
- **問5(解釈)**: D「請観其詩」。選択肢は**2×2マトリクス**: 〔見る対象=その人自身の詩/白石・南郭の詩〕×〔請の解釈=見せてくれるよう求めた/よく見なおすように求めた〕。全肢「白石・南郭の詩を悪く言った者に、〜ように求めた。」の統一枠。
- **問6(発言の内容説明)**: E「余因謂曰」以下の豊山の言葉(真瓦/偽玉の比喩)について。選択肢テンプレ=「豊山は、ある人が白石・南郭の詩を偽詩と批判するのに〔同意した上で/対し(表面上は同意しつつも)〕、詩の巧拙を「玉」「瓦」でたとえることによって、〜している。」**比喩の評価軸(真贋≠巧拙)のねじれ**を読めたかを問う。
- **問7(複数テクスト・新傾向)**: 柱書き「次の【資料】は本文と同じく豊山の文章である。**本文と【資料】の両方から読み取れる**、詩の評価に関する豊山の考えとして最も適当なものを、後の①〜④のうちから一つ選べ。」
  - 【資料】: 罫線ボックス内に訓点付き漢文 約45字(「余於詩無所偏好。不問其風調之異同、佳者取之。但生硬・拙俗、諷詠無韻致者、雖曰名人之所作、我則不取也。」)+ボックス内注3個(風調=詩風/諷詠=詩を朗唱する/韻致=気品や風情)+出典行「(『松陰快談』による)」。
  - 選択肢は全肢統一構造: 「世の詩人たちは、〔徒党を組んで詩の上手下手を争っている/作風にこだわって党派争いをしている〕が、重要なのは**〔評価軸X〕**である。名声の高い人物の作品であっても、**〔欠点Y〕**ものは評価に値しない。」
    - X: 世間の人々の評判/詩としての完成度/作風の独創性/表現の平易さ
    - Y: 親しみやすさに欠ける/風趣に乏しく稚拙な/独自の風格を持たない/奇をてらった作為の目立つ
    - **X・Yがともに両文書の趣旨と整合する肢が正解**(本文=巧拙重視・資料=韻致重視、名人の作でも取らない)。

## 4. 紙面仕様(共通・組版レベル)

- **縦書き・右→左**。1ページおおむね本文18〜20行(設問ページは字下げ・行間広め)。
- 大問見出し「第4問」「第5問」は行頭ゴシック。リード文がそれに続き、末尾に「(配点 45)」。
- 設問見出し「問1」「問2」…は段落頭ゴシック。柱書き定型文:
  - 単問: 「〜として最も適当なものを、次の①〜④のうちから一つ選べ。解答番号は N 。」
  - 群問: 「〜を、次の各群の①〜④のうちから、それぞれ一つずつ選べ。解答番号は N 〜 M 。」
  - 複数選択: 「〜を、後の①〜⑥のうちから二つ選べ。ただし、解答の順序は問わない。」
- **解答番号は四角囲みの算用数字**(横倒しでなく正立)。選択肢番号は丸数字①〜⑥。
- 傍線=文字の右側の実線。波線=文字の右側の波線。傍線ラベルは古文が(ア)(イ)(ウ)とa〜d、漢文が(ア)(イ)とA〜E(いずれもラベルを傍線始端の右肩に置く)。段落番号は四角囲み。
- 引用・資料は罫線ボックス囲み(問5会話文・問7【資料】)。ボックス内にも(注)を持てる。
- 注は本文末尾にまとめ、「(注) 1 語 ―― 定義。」形式・通し番号。
- 漢文の訓点: 返り点は字の左下、送り仮名は字の右下カタカナ、ルビは右側ひらがな。設問中の白文引用は字間を空けて「是 雖 狭 見 使 然」のように組む。
- 下書き用紙ページが大問間に挟まる(p37)。「(下書き用紙) 国語の試験問題は次に続く。」
- 各ページ右下に冊子コード(2101—NN)。左端中央に黒の綴じ目マーク。
