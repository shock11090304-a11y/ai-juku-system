## 2. 裏表紙「Ⅱ 解答上の注意」(印刷p46・スキャンp2) — マーク記法の定義(最重要)

1. 解答は解答用紙の問題番号に対応した解答欄にマーク。
2. 問題文中の **「ア」「イウ」など(太枠一重四角)には, 符号(−)又は数字(0〜9)** が入る。カナ1文字=マーク1個。例: 「アイウ」に −83 → ア=−, イ=8, ウ=3 (マークシート図例つき: 各行 −0〜9 の11個の丸)。
3. **分数**で解答する場合, 符号は分子につけ, 分母につけてはいけない。既約分数で答える (例: エオ/カ に −4/5。3/4 と答えるところを 6/8 は不可)。
4. **小数**は指定桁数の一つ下を四捨五入し, 必要に応じ指定桁まで **⓪** にマーク (例: 「キ.クケ」に 2.5 → 2.50)。
5. **根号**は中の自然数が最小になる形 (4√2, √13/2 と答える。2√8, √52/4 は不可)。
6. **二重四角 (例:「コ」)は選択肢から一つ選ぶ** 選択式マーク。
7. 同一の問題文中に「サシ」「ス」等が **2度以上現れる場合, 2度目以降は細字の枠** で表記する。

## 5. 第1問 (必答問題) (配点 15) — 図形と方程式(2円・軌跡の論理・絶対値付き不等式の領域)

**分野**: 数Ⅱ「図形と方程式」(円の方程式, 2円の位置関係, 束(2交点を通る直線)の論理, 不等式の領域)
**スタイル**: 純数学(会話文なし)。1本の設定で (1)→(2)(i)〜(iv) と深掘りする誘導型。
**ページ構成**: 印刷p4 設定 → p5 (1) → p6 (2)(i) → p7 (2)(ii) → p8 (2)(iii)(iv) → p9 図の解答群(丸々1ページ)。

### 設定 (印刷p4)
O を原点とする座標平面において, 方程式
- x² + y² − 7y + (2x − 5y + 25) = 0 ……① の表す円を C₁
- x² + y² − 7y − (2x − 5y + 25) = 0 ……② の表す円を C₂

★構造: 「共通部分 S(x,y)=x²+y²−7y」±「直線式 L(x,y)=2x−5y+25」という束構成が大問全体の仕掛け。

### (1) 数値マーク: 円の標準形化と位置関係 (印刷p5)
- C₁の中心の座標は (**アイ**, **ウ**)。 — アイ=2カナ(符号+1桁を想定した幅), ウ=1桁
- C₁の半径 r₁, C₂の半径 r₂, 中心間距離 d とすると r₁ = **エ**√**オ**, r₂ = **カ**√**キ**, d = √**クケ** である。
- 直後に地の文で結論を与える: 「r₁, r₂ と d の関係から, C₁ と C₂ は **2点で交わる** ことがわかる。」(これ自体は問わない)
- 答え(検算): 中心(−1, 6), r₁=2√3, r₂=3√3 (C₂中心(1,1)), d=√29。|r₁−r₂|<d<r₁+r₂。

### (2) 絶対値付き不等式 x² + y² − 7y + |2x − 5y + 25| < 0 ……③ の領域 (印刷p6〜9)
導入の地の文: ③の左辺は 2x−5y+25≧0 のとき①の左辺と一致し, 2x−5y+25<0 のとき②の左辺と一致する。

#### (i) 半平面の帰属判定 — 選択式2択×3スロット (印刷p6)
不等式 2x−5y+25≧0 の表す領域を D, 2x−5y+25<0 の表す領域を E とする。
- ・原点Oは「**コ**」に含まれる。 ・C₁の中心は「**サ**」に含まれる。 ・C₂の中心は「**シ**」に含まれる。 (箇条書き・各二重枠)
- 解答群(コ〜シ共通, 繰り返し可): ⓪ D ① E — **2択**
- 答え(検算): コ=⓪, サ=①, シ=⓪。

#### (ii) 2交点を通る直線の論理 — 選択式6択 (印刷p7)
方程式 2x−5y+25=0 ……④ の表す直線を ℓ とする。
地の文の誘導: 実数 x, y が①と②の両方を満たすとする。①と②の左辺どうし, 右辺どうしの差をとると 2(2x−5y+25)=0 となる。よって実数 x, y は④も満たす。
「したがって, 「**ス**」。このことから, ℓ は C₁ と C₂ の二つの交点を通る直線であることがわかる。」
- スの解答群(⓪〜⑤の6択, 「最も適当なものを一つ選べ」):
  - ⓪ 点Pをℓ上の点とすると, PはC₁上にあり, かつC₂上にもある
  - ① 点Pをℓ上の点とすると, PはC₁上にあるか, またはC₂上にある
  - ② 点PをC₁上にあり, かつC₂上にもある点とすると, Pはℓ上にある
  - ③ 点PをC₁上にあるか, またはC₂上にある点とすると, Pはℓ上にある
  - ④ 点PをC₁上の点, 点QをC₂上の点とすると, 直線PQはℓと一致する
  - ⑤ 点PをC₁上の点, 点QをC₂上の点とすると, 直線PQはℓと交わる
- 選択肢は「かつ/または」「順方向/逆方向の含意」を系統的に入れ替えた論理識別問題。答え(検算): ②。

#### (iii) F∪G の図示 — 図選択9択 (印刷p8)
- 不等式 x²+y²−7y+(2x−5y+25)<0 の表す領域と(i)の領域Dの共通部分を F とする。
- 不等式 x²+y²−7y−(2x−5y+25)<0 の表す領域と(i)の領域Eの共通部分を G とする。
- 「不等式③の表す領域は, FとGの和集合である。これを図示すると「**セ**」の灰色部分である。ただし, 境界線を含まない。」

#### (iv) 符号反転版 — 図選択9択 (印刷p8)
③において |2x−5y+25| の前の符号を+から−に変えた不等式
x² + y² − 7y − |2x − 5y + 25| < 0 ……⑤ を考える。「⑤の表す領域を図示すると「**ソ**」の灰色部分である。ただし, 境界線を含まない。」

#### セ・ソ共通の解答群 (印刷p9, 丸々1ページ・図9個を3×3配置)
前書き: 「「セ」,「ソ」については, 最も適当なものを, 次の⓪〜⑧のうちから一つずつ選べ。ただし, 同じものを繰り返し選んでもよい。なお, ⓪〜⑧では **座標軸を省略している**。」
全図共通の下絵: 左上に小円C₁・右下に大円C₂が2点で交わる(実際の配置を反映)。⑤〜⑧のみ2交点を通る直線ℓも描画。灰色網掛けの部分だけが異なる:
- ⓪ 線なし: C₁∩C₂ (レンズ) のみ灰色
- ① 線なし: C₁ 全体のみ灰色
- ② 線なし: C₂ 全体のみ灰色
- ③ 線なし: 対称差 (C₁∪C₂からレンズを除いた部分) が灰色
- ④ 線なし: C₁∪C₂ 全体が灰色
- ⑤ 線あり: レンズのうち **ℓより上側** の三日月形のみ灰色
- ⑥ 線あり: レンズのうち **ℓより下側** のみ灰色
- ⑦ 線あり: **C₁のうちℓより上側** (弓形, 上側レンズ含む) が灰色
- ⑧ 線あり: **C₂のうちℓより下側** (大弓形, 下側レンズ含む) が灰色
- 答え(検算): セ=⓪ (F=⑥の領域, G=⑤の領域, 和=レンズ), ソ=④ (符号を−にすると領域は C₁∪C₂ 全体に広がる, という意外性が出題意図)。

## 6. 第2問 (必答問題) (配点 15) — 三角関数(和積公式の導出と応用)

**分野**: 数Ⅱ「三角関数」(加法定理→和積公式の導出, 合成せずに済む同振幅波の和, パラメータ付き3項和)
**スタイル**: (1)(2)は純数学の誘導。(3)で **ICT活用場面(グラフソフト画面の図1)+花子・太郎の会話文**(破線枠)。
**ページ構成**: 印刷p10 (1) → p11 (2) → p12 (3)導入+図1+会話 → p13 (3)(i) → p14 (3)(ii)。

### (1) 和積公式の導出 (印刷p10)
二つの角 A, B に対し sinA + sinB = 2 sin((A+B)/2) cos((A−B)/2) ……① が成り立つことを示そう。
二つの角 α, β に対し, 加法定理から
- sin(α+β) = 「**ア**」 + cosα sinβ ……②
- sin(α−β) = 「ア(細字=2度目)」 − cosα sinβ ……③
②と③の左辺どうし, 右辺どうしを加え, α=「**イ**」, β=「**ウ**」とすると①が得られる。
- アの解答群(8択): ⓪sinα sinβ ①sinα cosβ ②cosα sinβ ③cosα cosβ ④sin²α ⑤sin²β ⑥cos²α ⑦cos²β
- イ・ウの解答群(8択共通, 繰り返し可): ⓪A ①B ②A+B ③A−B ④(A+B)/2 ⑤(A−B)/2 ⑥(A+B)/4 ⑦(A−B)/4
- 答え(検算): ア=①, イ=④, ウ=⑤。

### (2) ①の適用: 最大値 (印刷p11)
関数 f(x) = sin(x + (5/12)π) + sin(x + π/12) とする。0≦x<2π の範囲で f(x) の最大値を考えよう。①を用いると
f(x) = 2 sin(x+「**エ**」) cos「**オ**」 = 2 cos「オ(細字)」 sin(x+「エ(細字)」) と変形できる。
「2cos「オ(細字)」は正の定数であるから, 0≦x<2πの範囲において, f(x)は x=「**カ**」で最大値「**キ**」をとる。」
- エ〜カの解答群(8択共通, 繰り返し可): ⓪0 ①π/12 ②π/6 ③π/4 ④π/3 ⑤π/2 ⑥(3/4)π ⑦π
- キの解答群(8択): ⓪1/2 ①1 ②2 ③√2/2 ④√3/2 ⑤√2 ⑥√3 ⑦2√2
- 答え(検算): エ=③(π/4), オ=②(π/6), カ=③(π/4), キ=⑥(√3)。エとカが同値=繰り返し選択の実例。
- ★書式注意: 位相・定数とも数値マークでなく**選択式**。「2cosオは正の定数であるから」と符号の根拠を地の文で明示するのが共テ流。

### (3) パラメータ a 付き3項和 g(x) (印刷p12〜14)
a を 0<a<π を満たす定数とし, g(x) = sin(x+a) + sin(x+2a) + sin(x+3a) とする。

**図1** (印刷p12): 花子さんと太郎さんが y=g(x) のグラフを**コンピュータ(グラフ描画ソフト)**で表示した画面の模式図。
- 画面左側: ツールアイコン群(選択矢印/点/多角形/円/a=/移動 の6ボタン), 「a=[入力ボックス]」, スライダー(−○—+), 記号パッド(x y a / < > π), テンキー(7 8 9 / 4 5 6 / 1 2 3 / 0 + −)。
- 画面右側: 座標軸(x, y, 原点O)上に3本の曲線。右上に「y=g(x)」の枠ラベル。右下に凡例枠: 実線 a=0.5, 点線 a=1.0, 破線 a=1.5。
- 図の下に「図 1」キャプション。
- a=0.5 は振幅大きめの正弦波, a=1.0/1.5 と振幅が縮む様子が描かれる(g=(2cos a+1)sin(x+2a) を反映)。

**会話文**(破線枠, 印刷p12下部):
- 花子: 「g(x)は, 定数 p, q を用いて g(x)=p sin(x+q) と変形できそうだね。」
- 太郎: 「三つの関数 sin(x+a), sin(x+2a), sin(x+3a) のうちの二つの関数の和に①を使うと, 残り一つの関数の定数倍にできるかな。」

#### (i) 構造の発見 (印刷p13)
「①を用いると, 関数 sin(x+a), sin(x+2a), sin(x+3a) のうちの二つの関数の和「**ク**」は, 残りの関数 sin(x+「**ケ**」) の定数倍となる。したがって, 関数 g(x) は g(x) = 「**コ**」 sin(x+「ケ(細字)」) と変形することができる。」
- クの解答群(**3択**): ⓪sin(x+a)+sin(x+2a) ①sin(x+a)+sin(x+3a) ②sin(x+2a)+sin(x+3a)
- ケの解答群(**3択**): ⓪a ①2a ②3a
- コの解答群(8択): ⓪2cos a ①−2cos a ②2cos 2a ③−2cos 2a ④(2cos a+1) ⑤(−2cos a+1) ⑥(2cos 2a+1) ⑦(−2cos 2a+1)
- 答え(検算): ク=①(両端の和=2sin(x+2a)cos a), ケ=①(2a), コ=④(2cos a+1)。
- コの選択肢は「符号±」×「a/2a」×「+1の有無」の直積で組む。

#### (ii) 具体値での最大値 (印刷p14)
「a=(5/6)π のとき, 0≦x<2π の範囲において, g(x)は x=(**サシ**/**ス**)π で最大値「**セ**」をとる。」
- サシ/ス: **数値マーク**(分数×π の形。サシ=分子2桁, ス=分母1桁)
- セの解答群(**10択**): ⓪0 ①1 ②2 ③−1 ④−2 ⑤√3 ⑥−√3 ⑦√3+1 ⑧√3−1 ⑨−√3+1
- 答え(検算): 2cos(5π/6)+1 = 1−√3 <0 (係数が負になるのが仕掛け)。g=(1−√3)sin(x+5π/3) の最大は sin=−1 のとき → x=11π/6, 最大値 √3−1。サシ=11, ス=6, セ=⑧。
- ★(2)では「正の定数」と明示していた係数が, (ii)では負になる — 符号の吟味が本質。セの解答群は ±ペア(1/−1, 2/−2, √3/−√3, √3±1/−√3+1)で符号ミスを検出する構成。
