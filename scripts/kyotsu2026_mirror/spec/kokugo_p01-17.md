### 8.2 第1問そっくりさん生成レシピ

- **本文**: 実作者(美術・音楽等の表現者)視点の随筆的評論をオリジナルで書く。約**3,100字**(±10%)、形式段落約18。構成テンプレ:
  「幼少期の私的体験の回想(2〜4段落) → 体験の質の言語化(カギ括弧概念の導入) → 制作/実践論への展開+**理論家1名の参照(注付き)** → メタ的自己言及(「〜にすぎない。にもかかわらず…」) → 社会的一般化(交換/共有の限界) → 結論(実践の定義+贈与的な他者関係)」。
  文体特徴: カギ括弧付きキー概念を7〜8個反復 / 「——」挿入句 / 固有名詞は注に落とす(6項目前後、人名は生没年付き)。
- **傍線**: 漢字用カタカナ傍線(ア)〜(オ)を本文前半〜中盤に分散配置 + 内容傍線A〜Eを「体験の質 / 実践の定義 / メタ言及 / 一般化の帰結 / 結論」の5文に引く。
- **設問セット** (固定レシピ):
  1. 問1: 同音漢字4択×5 (解答番号1〜5)。誤答肢は同音別字。肢は5〜15字の短文、カタカナ部傍線。**正解位置は5問で偏らないよう均等化**。
  2. 問2: 傍線A どういうことか (4択・全肢末尾「〜ということ。」統一)
  3. 問3: 傍線B どういうことか (4択・全肢冒頭句も統一: 「◯◯においては、」)
  4. 問4: 傍線C 筆者はなぜこのように述べるのか (4択・「〜ため。」)
  5. 問5: 傍線D それはなぜか (4択・「〜から。」)
  6. 問6: 傍線E 筆者の考え (4択・完全平行構造: 「〜と考える筆者は、〜を、難しいながらも〜。」型のように骨格を揃える)
