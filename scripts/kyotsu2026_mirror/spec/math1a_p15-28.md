## 4. 第4問 場合の数と確率 (配点20) — PDF p.23〜28 (印刷24〜29) 【完全収録】

### 用語定義と表の凡例 — PDF p.24

### (1) 3人リーグ — PDF p.25

### 第4問の設計骨格 (複製レシピ)
1. **パラメータ**: 主役Aの勝率 p (実物2/3) と脇役同士の勝率 1/2。p は 3乗しても分母が扱える **1/3の倍数** が吉 (分母9, 27が並ぶ)。
2. **構造**: 「n人版とn+1人版で同じ量を計算して比較」+「優勝ルールに抽選(1/n)を混ぜる」のが核。小問勾配:
   - (1)(i) 全勝ケース=積を計算するだけ → (ii) タイ発生ケース: 巴の列挙(対称2通り)×抽選 → 和。
   - (2) 排反な場合分け(全敗者の有無)を**問題文が指定** → (i)は(1)(ii)の結果を部品として再利用 → (ii)は部分星取表から**残り試合の場合の数**を数えさせる([ソ]) → 総和 → 3人版との差と大小([ヌ])。
3. **表の文法**: 星取表 (斜線対角・○×・勝ち数/負け数/抽選✓—列) を「完全な例 (表1)」「対称タイの例 (表2)」「部分記入 (表3・表4)」「再掲 (表1(再掲))」の4形態で使い分ける。クローン時もこの4形態を作ること。
4. **数値整合の検証**: 全ケースをプログラムで全数列挙 (3人=2³, 4人=2⁶通りに勝敗確率を掛けて優勝確率を厳密和) し、各スロットの分数と桁数(クケ・スセ・ナニ=2桁分母)が一致することを機械検算する。

## 5. 紙面仕様 (レイアウト共通ルール)

- **ヘッダ**: 全ページ上部に科目名「数学Ⅰ，数学A」(ゴシック太字)。**外側寄せで交互** — 印刷偶数ページ(16,18,…)は左上、奇数ページ(17,19,…)は右上。

- **続きページの表記**: 大問がページをまたぐ場合、各ページ末尾右寄せに「(数学Ⅰ，数学A第◯問は次ページに続く。)」。大問最終ページには付かない。
- **空欄(マークスロット)の枠**:
  - 数値記入スロット = **一重の細枠** (例: [イ], [オカ])。連結桁は1つの横長枠に2文字 (「オカ」「チツ」「サシ」「スセ」「クケ」「ナニ」)。
  - 選択式スロット = **二重枠** (例: [タ][テ][ナ][ア][エ][ソ(第3問)][ヌ])。本文中の枠と解答群見出し「[X] の解答群」の両方が二重枠。
  - 分数 = 分子枠/横棒/分母枠の縦積み。根号 = [ケ]√[コ] のように√記号の中に枠。小数 = 「0.[チツ]」のように整数部印字+小数部のみ枠。比 = 「[キ] : [ク]」。
  - **既出スロットの再掲** (灰色にせずそのまま同じ枠で再表示) が多用される: 「[ア]/[イ] + [キ]/[クケ]」「[ウ]/[エ] × [オ]/[カ]」等。
- **解答群**: 「[X] の解答群」ラベルの後に罫線枠。選択肢は ⓪①②…の白丸数字。少数なら横一列 (⓪ < ① = ② >)、多数なら複数行×複数列 (タは2行5列)、文章肢なら縦並び、正誤組合せは**表** (列=⓪〜③, 行=(a),(b))。「最も適当なものを、次の⓪〜⑨のうちから一つ選べ。」が典型文言。
- **条件ボックス**: 「仮定1」「仮定2」「優勝者の決め方」= 角丸長方形の枠、**見出し語を枠線上端に重ねて**配置。中身は1〜4行。

- **余白**: 内容が少ないページ (p.16, p.21, p.24) も詰めずに大きな余白のまま。計算余白を確保する紙面思想。
