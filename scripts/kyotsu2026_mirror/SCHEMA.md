# 作問パートモジュール仕様 (content/*.py)

作問エージェントは `SECTIONS`(大問リスト) と `ANS_SECTIONS`(解答リスト) を定義した
Pythonモジュール(例: `content/math1a_a.py`)を書く。LaTeXを含む文字列は raw string
(`r"..."`)推奨。マージャ(`math1a.py`等)が結合するので、自分の担当大問だけ書けばよい。

## 横書き(数学・英語) SECTIONS

```python
SECTIONS = [
  {"no": 1, "points": 30,            # 大問番号・配点
   "optional": "選択問題" (任意),     # 選択大問のみ
   "parts": [                        # 〔1〕〔2〕やA/B。区切り不要なら label:"" 1個
     {"label": "〔1〕", "blocks": [BLOCK, ...]},
   ]},
]
```

### BLOCK型(横書き)
- `{"t":"p","text": r"..."}` — 地の文。**`$...$`=LaTeX数式**、`〔ア〕`=数値マーク欄(一重枠)、`〚ア〛`=選択式マーク欄(二重枠)。`<b><u><i><br><ruby><rt>`可。`indent`:True で字下げ。
- `{"t":"m","tex": r"S=\int_0^2 ..."}` — 別行立て数式。**空欄はLaTeX内にカタカナをそのまま書く**(例 `r"\frac{アイ}{ウ}"` → 自動で1字ずつ枠囲みされる)。マイナス符号スロットも `アイ` のように枠2個(符号は1枠占有)。
- `{"t":"choices","for":"ア","auto_intro":True,"items":[r"$2\sin\theta$", ...],"cols":4}` — ⓪①②…の解答群。`auto_intro` で「〔ア〕については，最も適当なものを…」定型文。`for` に文字列を渡し `auto_intro` 無しなら見出しをそのまま表示(例 `"〔シ〕，〔ス〕の解答群（同じものを繰り返し選んでもよい。）"`)。
- `{"t":"q","qlabel":"1","no":3,"points":4,"stem":"...","choices":[...],"cols":1}` — 英語型設問。マーク番号ボックスはstem末尾に自動付与(位置指定は stem 中に `{Q}`)。選択肢は①開始。`multi`:True なら「二つ選べ」系(見た目同じ)。
- `{"t":"fig","svg":"<svg viewBox='0 0 400 260' width='400'>...</svg>","caption":"図1 ..."}` — 図。SVGは self-contained(外部参照禁止)、stroke #333、font-size 11〜13、width属性px(1mm≈3.78px)。
- `{"t":"table","head":[...],"rows":[[...]],"caption":"表1 ..."}` — 罫線表。セルに `$..$` 可。
- `{"t":"convo","turns":[{"sp":"太郎","text":"..."},{"sp":"花子","text":"..."}]}` — 会話(実物は破線枠+氏名)。
- `{"t":"boxnote","title":"条件1","lines":["...", ...]}` — 枠囲み(条件・方針・ルール等)。
- `{"t":"html","html":"..."}` — 自由HTML。英語素材用コンポーネントclass: `.mat .mat-t`(汎用枠) `.chat .cname .bub .me .stamp`(チャット) `.web .web-bar .web-in .comment .cwho`(Web記事) `.email .ehead .ebody`(メール) `.flyer .f-title .f-sub`(チラシ) `.slides .slide .s-t`(スライド2列グリッド) `.hnote`(手書き風メモ枠) `.handw`(手書き風フォント) `.outline .o-t`(アウトライン枠) `.twocol`(本文+コメント2カラム)。
- `{"t":"pagebreak"}` / `{"t":"vspace","mm":6}`

## 縦書き(国語) SECTIONS — parts でなく units

```python
SECTIONS = [
  {"no": 1, "points": 45, "units": [UNIT, ...]},
]
```

### UNIT型(縦書き)
- `{"t":"lead","text":"次の文章を読んで，後の問い（問1〜6）に答えよ。"}` — 前書き(配点は書かない・帯に自動表示)。
- `{"t":"para","text":"..."}` — 本文段落(自動字下げ・`noindent`:True で無効)。インライン: `<lA>…</lA>`=傍線部A(A〜F, ア〜オ, 1〜6可)、`<wv>…</wv>`=波線、`<bx>…</bx>`=四角囲み、`<b><u><br><ruby><rt>`可。**本文中の数字は漢数字で書く**(算用数字は解答番号など最小限)。
- `{"t":"h","text":"【文章】"}` — ゴシック見出し。
- `{"t":"note","items":[["1","語","説明"], ...]}` — (注)。
- `{"t":"q","qlabel":"一","no":23,"points":7,"stem":"傍線部Ａ「…」とあるが…。最も適当なものを，次の①〜⑤のうちから一つ選べ。","choices":["...", ...]}` — 設問。5択なら choices 5個。
- `{"t":"kanbun","rows":[{"ch":"楚","ruby":"そ"},{"ch":"人","ok":"ニ"},{"ch":"有","kaeri":"レ","ok":"リ"},{"punc":"。"},...]}` — 漢文白文+訓点。`ch`=漢字1字, `ok`=送り仮名(カタカナ・歴史的仮名遣い), `kaeri`=返り点(レ/一/二/三/上/中/下), `ruby`=よみ, `line`="Ａ"で傍線, `punc`=句読点。
- `{"t":"waka","lines":["五七五七七を1行で", ...]}` — 和歌・漢詩の書き下し等(字下げ表示)。
- `{"t":"convo_v","turns":[{"sp":"Ｎさん","text":"..."}]}` — 対話(縦書き)。
- `{"t":"hframe","height_mm":90,"width_mm":120,"html":"..."}` — **横組み資料**(実用文の図表等)。html内: `.doc .doc-t`(資料枠+題), table, `.src`(出典右寄せ)。縦フロー中に埋め込まれる。height_mm は中身が収まる高さを指定(過小だとはみ出す)。
- 国語の設問stem内にマーク番号を出す場合も `{Q}` は使えない(自動でstem末尾に付く)。

## ANS_SECTIONS (全科目共通の器)

数学(スロット表+解説):
```python
ANS_SECTIONS = [
  {"section": 1,
   "slots": {"ア": "4", "イ": "9", "ウ": "−", "エ": "①", ...},  # 1枠=1文字。数字/−/①〜⓪(選択式)
   "kai": [  # 解答編の解説(横書きBLOCK型が使える)
     {"heading": "〔1〕 集合と命題", "blocks": [{"t":"p","text":"..."}, {"t":"m","tex":"..."}]},
   ]},
]
```
- **slots のキーは印刷順に全マーク枠を1枠ずつ**。連結枠「アイ」は "ア","イ" の2キー。
- 選択式枠の値は `"⓪"〜"⑨"` の丸数字文字列(解答群の並び順で0始まり)。

国語・英語(設問表+解説):
```python
ANS_SECTIONS = [
  {"section": 1, "points": 45,
   "answers": [{"qno": 1, "answer": "②", "points": 2}, ...],   # qno=マーク番号(通し)
   "kai": [{"heading": "問1", "blocks": [{"t":"p","text":"正解②。本文第二段落で…(根拠と誤答の切り方)"}]}, ...]},
]
```
- `answer` は丸数字文字列。複数選択(順不同)は `"②・④"` のように中黒連結し qno を枠数ぶん並べる(例: 22, 23 両方に同じ表記)。

## 品質規則(必須)
1. **オリジナル作問**: 実物の本文・数値・選択肢を流用しない。分野/形式/設問数/選択肢数/マーク数/配点/難易度勾配はspecに一致させる。
2. **数学は全スロット機械検証**: `content/verify_<part>.py` を書き、sympy/全数列挙で各スロット値を独立に導出して assert。全pass後に完了報告。
3. **正解位置の分布**: 4択・5択の正解番号が偏らない(同番号3連続禁止・全体で均す)。選択式スロット⓪〜も同様。
4. **自己完結**: 各設問はその紙面情報だけで解ける。図表参照は「図1」等の番号で。
5. 完了前に必ず単体ビルド検証:
   `python3 /Users/adachishouhei/ai-juku-system/scripts/kyotsu2026_mirror/build/check_part.py <自分のファイル> [--vertical]`
   が `CHECK OK` になること(縦書きパートは --vertical)。
6. 解説(kai)は生徒が読む前提で、正解の導出+主要な誤答の切り方まで。数学は途中式を `{"t":"m"}` で。
