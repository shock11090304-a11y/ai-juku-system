# 高校英文法レベル1 標準演習（偏差値55〜60）

`grammar-1`（英文法レベル１・`payment/courses.json`）のクラス用。
**時制 / 不定詞 / 動名詞 / 仮定法** の4分野 × 各30問 = **120問**。

既存の `scripts/grammar_workbook`（基礎定着問題集・全20分野500問）の**次に置く1冊**。
基礎で「形を覚えたか」を問うのに対し、こちらは「どちらの形か・なぜその形か」を問う。

| | 基礎定着問題集 | この問題集 |
|---|---|---|
| 想定 | 高1〜基礎固めの高2 | 偏差値55〜60を狙う層 |
| 時制 | 現在形/過去形/現在進行形、規則・不規則変化 | 名詞節と副詞節の見分け、完了進行形、未来完了、時制の一致、状態動詞、進行形の受動 |
| 不定詞 | 3用法の見分け、want to do | 前置詞の残留、意味上の主語 for/of、完了不定詞、使役の受動、be to、結果の不定詞、否定の位置 |
| 動名詞 | 目的語に ing をとる動詞の暗記 | to が前置詞の慣用表現、完了動名詞、意味上の主語、受動の動名詞、to と ing で意味が変わる動詞 |
| 仮定法 | 仮定法過去/過去完了の基本形、I wish | 混合仮定法、if 省略の倒置、if 節の代用、It is time、would rather、要求提案の that 節、otherwise |

各問に `[標準]`（偏差値55前後）/ `[発展]`（60前後）を付けてある。
**まず [標準] だけを通しで解かせ、8割を超えてから [発展] に進む**運用を想定。

出題形式は基礎定着問題集と同じ3種：四択18問 / 整序英作文7問 / 書き換え5問（1分野あたり）。

## 作り方（触る順番）

```
content/*.py          ← ★ここだけを人間が編集する
   ↓  python3 make_units.py
units/*.json          ← 生成物。直接編集しないこと
   ↓  python3 build_pdf.py
高校英文法レベル1_標準演習_….pdf   （.gitignore 対象。刷るたびに作る）
```

検査は2本：

```
python3 check.py       # データを見る。CI でも回る（run_all_gates.py が拾う）
python3 build_pdf.py && python3 check_pdf.py   # 刷った紙を見る。手元専用
```

`check_pdf.py` は `fitz`(pymupdf) を import しているので、`run_all_gates.py --no-pdf`（CI）は
自動で外して「刷ったPDFが要る＝ここでは検査していない」と一覧に出す。
**紙を刷ったら手元で `--no-pdf` なしで回すこと。**

## 人間に決めさせない3か所（make_units.py）

手で書くと必ず壊れるので、素データからは機械が決める。

1. **`answer_index` / `answer_text`** — 素データは正解を*文字列*でしか持たない。番号は
   `choices` から引き直すので、青学の教材を実際に壊した
   `[MC MATCH]`（`choices[answer_index] != answer_text`）が構造的に起こりえない。
2. **正解の位置** — 素データの `choices` は「教えやすい順」（正解が先頭に来がち）。
   単元ごとに固定配列 `POSITIONS` で 0〜3 を配り直す。全体で均すのではなく**単元ごと**に
   均すのは、生徒が単元単位で解くから（共通テスト模試で大問ごとに配るのと同じ理由）。
3. **整序の `tokens`** — 答えから機械的に切り出して決定的に並べ替える。
   手で書き写すと語の過不足が起きるうえ、**既存の `grammar_workbook` では4問が
   答えと同じ並びのまま印字されていて、問題編に答えがそのまま出ていた**（下記）。
   ここでは並べ替え後に同一並びを禁止している。

乱数は使わない。seed を変えると全問の tokens が入れ替わり、差分が査読できなくなる。

## check.py が見るもの

| | 内容 |
|---|---|
| A 素データ同期 | `units/*.json` が `content/*.py` から作り直したものと1バイト違わないか |
| B 構造 | 件数・番号・type・level・必須フィールド |
| C mc | 選択肢4つ・重複なし・`answer_index` と `answer_text` の一致・`( )` の有無 |
| D 正解の偏り | 単元内で 0〜3 が 4〜5回ずつ／同じ位置が3連続していないか |
| E 最長肢テル | 単独で最長の正解が目立ちすぎないか（3文字超の差／単元で60%超） |
| F 整序の漏洩 | `tokens` が答えと同じ並びになっていないか／語の過不足がないか |
| G 語順の一意性 | 大文字で始まる語（固有名詞と I を除く）が文頭の1語だけか／**位置が動きうる語を含む整序は1問ずつ理由付きで宣言させる** |
| H 解答漏洩 | 書き換えの答えが問題編の印字テキストに出ていないか |
| I 解説 | 3文以上／正解の語を含む／**誤答3つすべてに言及**しているか |
| J 禁止文字 | スマートクオート・ダッシュ・不可視スペース・絵文字 |
| K 重複 | 同じ設問文・同じ答えを2度聞いていないか |

`check_pdf.py` は紙で P1 豆腐 / P2 取りこぼし / P3 問題編への解答漏洩 を見る。

## 整序で「正解が2通り」になる事故（2026-08-17 の再点検で6問見つかった）

英語には位置が動く語があり、模範解答と違う語順を書いた生徒を**不当に×にしてしまう**。
初版の120問中6問がこれに当たっていた。

| | 模範解答 | 同じく正しい別解 |
|---|---|---|
| 時制 | the train had **already** left | the train had left **already** |
| 時制 | is being built **now** | is **now** being built |
| 時制 | since I **last** saw him | since I saw him **last** |
| 動名詞 | three hours doing … **yesterday** | three hours **yesterday** doing … |
| 仮定法 | would be in Tokyo **now** | would **now** be in Tokyo |
| 仮定法 | turn **down** the offer | turn the offer **down**（分離可能な句動詞） |

6問とも、可動副詞・分離可能な句動詞を使わない文に差し替えた。

そのうえで `check.py` に `[ORDER AMBIG]` を入れた。`MOBILE_ADVERBS` / `PARTICLES` の語を含む整序は、
**`ORDER_ADVERB_OK` に1問ずつ「なぜ動かないか」を英語で確かめて書かないと落ちる**。
現在11問が宣言済みで、検査のたびに理由が全部印字される。使われなくなった宣言も落とす
（「宣言があるから安全」と次の人が誤解しないように）。
**問題を足すときは、可動副詞を避けるのが一番安い。**

## 機械にできなかったこと（手で見た）

**四択の誤答は正解と同じ動詞の活用形でそろえる。** 初版で「This is the first time I ( ) natto」の
正解を `have eaten` にしたまま誤答に `try` / `tried` を残していた。三つが try で一つだけ eat なので、
文法を知らなくても仲間はずれで当てられる。手の目視で見つけて直した。

これを機械化しようとしたが、**使える形にならなかったので入れていない**。選択肢の語幹（末尾語の
先頭3文字）でグループ分けして「2グループなら怪しい」とすると、come/came・buy/bought・
break/broke・speak/spoken のような不規則変化が全部引っかかり、**正しい25問が誤検出**された。
雑音を出すゲートは読まれなくなるので入れない方がまし、と判断した。
**改訂で問題を足すときは、四択の誤答が正解と同じ語のバリエーションになっているかを目で見ること。**

## 既存 grammar_workbook で見つけた同型の欠陥（別途修正済み）

`scripts/grammar_workbook/units/12_subjunctive.json` の整序4問（no.16/17/19/20）で
`tokens` が答えと同じ並びのままになっており、**配布済みの500問PDFの問題編に答えが印字されていた**。
`validate.py` は語の多重集合しか見ておらず、並び順を見ていなかったため素通りしていた。
tokens を並べ替えたうえで、`validate.py` に `[ORDER LEAK]` 検査を足してある。
