## 1. PART1（第1部 一問一答・40問）

```python
PART1 = [
    {"group": "Ａ　中1　物質のすがた 13問", "items": [
        {"q": "設問文（1文で完結。「〜を何というか。」の形）",
         "ans": "解答（用語1つ。許容形は「電気抵抗（抵抗）」のように括弧で）",
         "exp": "解説2〜3文。まちがえた生徒がその場で理解できる密度で。"},
        ...
    ]},
    ...
]
```

- 40問ちょうど。1問1点。
- **`ans` は用語そのもの**。「〜のはたらき」のような説明文にしない。
- `exp` は必ず埋める（空だとゲートで FAIL）。

## 2. PART2（第2部 大問・合計36点）

```python
PART2 = [
    {"no": "大問1", "title": "見出し", "point": 9,
     "intro": "実験・資料の説明文。図表の前提条件はここに書く。",
     "figs": [ stat_table(...), figrow([...]) ],     # 省略可
     "qs": [ q, q, q, q, q ]},                        # 小問の pt 合計 == point
    ...
]
```

小問 `q` の型は4つ:

```python
# ① 4択
{"type": "mc", "pt": 1,
 "q": "…最も適切なものを1つ選べ。",
 "choices": ["…", "…", "…", "…"],
 "ans": 1,                      # ★0 始まりの index。1始まりで書くと全問ズレる
 "exp": "正解の理由と、誤答が誤りである理由。"}

# ② 計算
{"type": "calc", "pt": 2, "unit": "Ω",     # unit は解答欄に印刷される単位
 "q": "…は何Ωか。",
 "ans": "50Ω",                              # ★unit と一致させる（"50A" は FAIL）
 "work": "直列の合成抵抗 ＝ 20 ＋ 30 ＝ 50Ω",   # 途中式。\n で複数行可
 "exp": "考え方の説明。"}

# ③ 記述
{"type": "desc", "pt": 2, "limit": 40,
 "q": "…その理由を説明せよ。",
 "ans": "…から。",                           # ★limit 字以内（機械で数え直す）
 "keys": ["…にふれている", "…にふれている"],   # 採点のポイント
 "exp": "解説。"}

# ④ 記号の組み合わせ（語群から選んで欄に入れる）
{"type": "match", "pt": 2,
 "q": "…にあてはまるものを、語群から選べ。",
 "pool": ["ア　…", "イ　…", "ウ　…", "エ　…"],
 "slots": ["Ａ", "Ｂ", "Ｃ"],
 "ans": ["ア", "ウ", "エ"],
 "exp": "解説。"}
```

## 3. PART3（第3部 短文記述・8問×3点＝24点）

`type` は全部 `"desc"`。`pt` は書かなくてよい（3点固定として計算される）。
`limit` は 30〜50 字。`keys` 必須。

## 4. POINTS（ポイント整理・4〜6件）

```python
POINTS = [
    {"h": "見出し", "body": "1〜2文の説明", "list": ["…", "…", "…"], "rule": "★ここを間違える、の一言"},
]
```

**★POINTS は解答解説編の巻頭にしか印刷されない。** だから答えを書いてよい。
逆に PART1〜3 の設問文・intro・図表には答えを書いてはいけない。

## 5. ★★ 落ちやすい機械ゲート（先に読むこと）

| ゲート | 何を見るか | 対策 |
|---|---|---|
| **解答漏洩** | 第1部の答え（2字以上）が、問題編に印字される**他のどこか**に出ていないか。他の設問文・大問のintro・図表の中身・選択肢すべてが走査対象 | 「沸点」を(11)の答えにしたら、(12)の設問文に「沸点」と書かない。大問の intro に「中和」と書いたら中和は一問一答から外す |
| **正解位置の偏り** | 4択の正解が特定の番号に偏っていないか（半数超で FAIL） | 正解を①②③④に散らす |
| **正解肢が最長のテル** | 正解肢が最長の問題が半数を超えていないか | 誤答肢も同じくらいの長さにする |
| **記述の文末** | 「理由・なぜ・原因・わけ」を聞いていないのに模範解答が「〜から。」で終わっていないか | 「利点を説明せよ」→「〜できる。」で終える |
| **採点キー整合** | `keys` の内容語が模範解答に1つも出てこない、という自己矛盾 | keys は模範解答の言葉で書く |
| **字数** | 模範解答が limit を超えていないか（機械で数え直す） | 書いたら自分で数える |
| **単位** | calc の `unit` と `ans` の単位が食い違っていないか | 「答 ___ g」の欄に "0.30" だけ入れず "0.30g" と書く |
| **配点** | 小問 pt の合計＝大問 point、第1部40＋第2部36＋第3部24＝100 | 大問ごとに 9 点になるよう pt を割る |
| **解説の①②③④** | 解説が正解の番号を「誤答」として説明していないか | 解説に丸数字を書かない（安全側） |
| **文字** | 絵文字・制御文字（PDFで黒四角になる） | 絵文字を使わない。★●◆▲ は可 |

## 6. 内容の質（機械では測れないので自分で守る）

- **誤答肢が正解になっていないか**。4択は「4つとも、資料や定義で真偽を判定できる」形にする。
- **中学の範囲を超えない**。高校内容（モルの計算、対数、三角比、イオン化傾向の詳細など）は出さない。
- **同じ論点を2回聞かない**（第1部と大問と記述で同じことを聞かない）。
- **正解が1つに決まる**か、必ず自分で反例を探してから確定する。
- 数値を含む事実（統計・順位・シェア）は**年で入れ替わる**。社会は必ず一次情報を確認し、
  出典と年次をファイル冒頭のコメントに書く。順位そのものは原則として出題しない。
