# 入試問題道場「弱点克服」中学プール 増量 v3 — 作問仕様 (作問エージェントが読む正典)

対象: 公立高校入試 **標準** レベル (中1〜中3・2021年度学習指導要領の範囲)。1単元 **34問** (読解単元は本文8本×4問=32問)。
出力は JSON 配列。1問 = 次のオブジェクト (キー名・型は厳守):

```json
{"subject":"英語","part":"eng","filter":"比較","unit":"比較",
 "stem":"次の文の( )に入る最も適切なものを選びなさい。\nThis bag is ( ) than that one.",
 "passage":"", "choices":["heavier","heavy","heaviest","more heavy"], "answer_index":0,
 "explanation":"【単元】比較。正解は「heavier」。あとに than があるので比較級を使う。heavy は短い語なので -er をつけて heavier にする。more heavy とは言わない。",
 "form":"空所補充", "level":"標準"}
```
- `filter` と `unit` は指示された単元名と**完全一致** (1文字も変えない)。`passage` は読解以外は `""`。
- `answer_index` は 0 始まり。`choices` は 4 つとも**相異なる**文字列。
- `form` は出題形式の短い名前 (空所補充 / 語形変化 / 並べかえ / 対話応答 / 書きかえ / 正誤 / 用語 / 計算 / 文章題 / 読解内容一致 など)。`level` は 基礎 / 標準 / やや応用。
- 配分の目安: 基礎 3 割・標準 5 割・やや応用 2 割。**単元全体を偏りなく**カバーし、同じ論点を 3 問以上作らない。

## 1. 正解の一意性 (最重要)
- 正解はちょうど 1 つ。**4 つの選択肢をすべて当てはめた全文・全ケースを自分で作って**、誤答 3 つが「誤り」または「文脈上あり得ない」ことを確かめる。「やや不自然」程度の誤答は使わない。
- 正解と同じ意味・同じ値・同じ形になる選択肢を入れない (= 2 正解)。英語は口語で広く許容される形も正解として数える。
- 誤答は中学生が実際にやる典型ミス (符号・活用・時制・数値の取り違え・よく似た用語) にする。荒唐無稽な選択肢は不可。
- 図・表・グラフが無いと解けない問題は作らない。必要な条件はすべて文章で書く (自己完結)。
- 事実 (年号・人名・制度・地名・数値・法則・語義・活用) は中学教科書の定説に一致させる。諸説ある事項・年で変わる統計・時事は正解にしない。制度は現在のもの (選挙権 18 歳・衆議院 465・参議院 248・消費税 10%)。

## 2. 「読まずに当たる」選択肢を作らない (盲検では見つからないので作問時に守る)
1. **長さ・具体性をそろえる**: 正解だけ長い／詳しい／短い、を作らない。4 つを同じくらいの字数・同じ粒度で書く。
2. **形をそろえる**: 4 つの品詞・形・単位・桁をそろえる (助動詞の問題なら 4 つとも助動詞。「to +原形」が 1 つだけ、分数が 1 つだけ、負の数が 1 つだけ、は不可)。「形が 1 つだけ違う選択肢」は必ず誤答に見えてしまう。
3. **正解の形を偏らせない**: 単元全体で「答えはいつも to +原形」「答えはいつも最上級」「X 正・Y 誤」ばかり、にならないよう形式を混ぜる。
4. **複数の要素を組み合わせた選択肢** (例:「20 N・1.0 m」「ア 尊敬語 イ 謙譲語」) は **2×2** にする: 各要素の値がちょうど 2 回ずつ出るようにし、どの要素でも正解の値が単独最多にならないようにする。並べかえ・順序の問題も、誤答を「正解の一部だけ入れ替えたもの」にしない。
5. 設問文に正解の語をそのまま書かない (用語の定義をそのまま書いて同じ語を選ばせる等)。
6. 理由と結論の組み合わせの選択肢では、矛盾する組 (結論だけで消せる) を誤答にしない。

## 3. 解説 (`explanation`)
- 必ず `【単元】<単元名>。正解は「<正解の選択肢の文字列そのまま>」。` で始める。正解テキストの末尾が `。` `.` `?` なら「。」を重ねない。
- 続けて中学生向けに 1〜3 文: 正解の根拠 (規則・計算の途中の値・年号など) と、典型的な誤答が誤りの理由を 1 つ。**値・語で書く**。
- **位置語 (ア/イ/ウ/エ・A/B・①②・「2 番目の選択肢」) は stem にも explanation にも絶対に書かない** (選択肢は後で入れ替わる)。並べかえ問題で「文の中で 3 番目に来る語」と文中の語順を言うのは可。
- 解説の中で**他の単元の名前を書かない** (指示される「避ける語」の一覧)。配信 API が問題全文を単元名で検索するため、他単元の名前を書くとその単元のカードに混ざる。文法用語として避けられないもの (「過去分詞」「比較級」など) は可。

## 4. 重複の回避
- 渡される `stems_<part>.json` (本番の既存問題文・単元ごと) を読み、**同じ設定・同じ問い方の問題を作らない**。数値・語・文脈・問い方を変える。
- 自分の 34 問の中でも「名前や数だけ入れ替えた同じ枠」を作らない。形式 (`form`) を 5 種類以上に散らす。
- 隣の単元 (同じファイルの他のキー) にすでにある問いと同じにならないようにする (単元をまたぐ重複は後で見つけにくい)。

## 5. 表記
- 英語の名前は Ken / Emi に偏らせない (Aya, Daiki, Mika, Ryo, Sora, Haru, Mr. Brown, Ms. Lee など多様に)。実在の人物・作品は出さない (歴史・社会の教科書事項は別)。
- 数学: 文字だけで書く。√ ・ ² ・ ³ ・ ≦ ・ ≧ ・ × ・ ÷ ・ ° ・ π はそのまま記号で、分数は `(1/2)x` の形。LaTeX (`\frac` `$`) は使わない。負の数は `-3`。
- 国語: 下線は出せないので問う語句は `〔 〕` で囲む。古典の引用は**作者の没年が 1955 年以前**の作品 (古文・近代の著名作) か自作に限る。
- 改行は `\n`。表・図は使わない。

## 6. 教科ごとの要点
- **英語**: 文法・語法・適語補充・語形変化・並べかえ (「3 番目に来る語」等)・対話応答・同意文書きかえ・会話定型句。中学範囲: 関係代名詞は主格 who/which/that と目的格 which/that のみ (whose・whom は使わない)。「I wish +過去形」「If I were you, I would 〜」は中3 必修 (助動詞の単元で可)。ネイティブが認める正解が 1 つに定まる文だけ。
- **数学**: 数値は厳密に計算し、解説に途中の値を書く。文章題は条件をすべて書く。図形 (合同・相似・円周角・三平方) は「AB=6cm, BC=8cm, ∠B=90°」のように文章で完全に条件を与え、一意に決まる問いにする。証明の単元は合同条件・対応する辺や角・証明の穴埋め (文章) を問う。確率は全列挙で確認する。データの活用はデータを列挙して与える (中央値・四分位範囲・相対度数・箱ひげ図の読みを文章で)。
- **国語**: 漢字 (読み・書き・同音異義語・同訓異字)、語句 (慣用句・ことわざ・四字熟語・対義語)、文法 (品詞・活用形・文節・係り受け・助詞助動詞の識別)、敬語 (尊敬・謙譲・丁寧の識別と正しい使い方。誤答にも正解と同じ種類の誤用 (二重敬語・動作の主の取り違え) を入れる)、古文 (歴史的仮名遣い・古語・係り結び・主語の判定・基本文法)、詩歌 (表現技法・季語・切れ字・句切れ・形式)。
- **理科**: 教科書の用語・法則・数値・単位・実験結果。実験は 1 段落の文章で装置と結果を説明する。用語は顕性・潜性 (優性・劣性は使わない)。計算は単位を明示。
- **社会**: 教科書の事実 (公立入試頻出)。地理は地形・気候・産業・人口・時差の計算、歴史は出来事の因果と順序 (年代の並べかえは 2×2 を守る)、公民は憲法・人権・三権・経済のしくみ・国際機関。資料読み取りは数値をすべて文章で与える。
- **読解 (英語 長文読解 / 国語 説明的文章・文学的文章)**: 本文は**完全オリジナル** (実在の著作物の引用・改変は禁止)。英語 120〜200 語、国語 300〜450 字。1 本につき 4 問。各問は本文だけを根拠に正解が一意に決まるもの (内容一致・指示語・理由・心情・要旨)。4 問は別々の箇所・別々の観点を問う。選択肢は 4 つとも本文の語句を使った同じくらいの長さの文にする。

## 7. 出力先
`scripts/chugaku_dojo/expand_v3/drafts/<part>__<gi>.json` に **JSON 配列のみ** を Write ツールで保存する (前置きの文章やコードフェンスは入れない)。保存後、件数と `form` の内訳だけを 3 行以内で報告する。
