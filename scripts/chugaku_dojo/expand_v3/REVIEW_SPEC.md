# 独立レビューの仕様 — レビューエージェントが読む正典

対象: `scripts/chugaku_dojo/expand_v3/verified/<part>__<gi>.json` (指示されたファイル群)。各要素 `{subject, part, filter, unit, stem, passage, choices, answer_index, explanation, form, level}`。
これらは盲検 3 名が全員正解した問題です。盲検では見えない欠点だけを探してください。

## 見るもの (指示されたレンズ)
- **R1 重複と範囲**: (a) 「名前・数値・物だけ入れ替えた同じ枠」(同じ論点を同じ文型で問う) が単元内・単元間 (渡されたファイル全部) にないか → 後ろの方を drop。別の例文で同じ文法項目を練習するのは反復であって重複ではない (ほぼ同一の文だけを潰す)。(b) 中学 (2021 年度学習指導要領) の範囲外・公立入試標準より明らかに難しい → drop。(c) 設問文・選択肢・解説に他単元の名前 (渡される一覧) が混ざっている → fix_expl (設問文に混ざっている場合は drop)。
- **R2 癖と解説**: (a) 読まずに当たる: 正解だけ長い／詳しい、形が 1 つだけ違う選択肢 (= 必ず誤答)、複合選択肢で正解の要素が多数派、設問文に正解の語が書いてある、理由と結論が矛盾する誤答 → drop。(b) 解説の誤り: 文法の断定が誤り (「〜という形は無い」等)、計算・年号・用語の誤り、正解の根拠になっていない → fix_expl (解説全文を書き直し、必ず正解の選択肢の本文を含める。位置語 ア/A/①/N 番目 は禁止)。(c) 正解が実は 2 つある・正解が誤っている (盲検を通っても起こる) → drop (理由に自分の答えを書く)。数学は Bash で python3 を回して計算を確かめてよい。理科・社会・国語の事実は WebSearch で裏取りしてよい。

## 出力
`scripts/chugaku_dojo/expand_v3/blind/review_<part>_<R1|R2>.json` に JSON 配列のみを Write ツールで保存:
```json
[{"stem":"<問題文を 1 文字も変えずにコピー>", "action":"drop", "reason":"同じ枠: eng4-03 と比較級+than の空所で名詞だけ違う"},
 {"stem":"<問題文>", "action":"fix_expl", "reason":"解説の『比較級は than が必須』は誤り", "explanation":"【単元】比較。正解は「heavier」。あとに than があるので…"}]
```
- 指し示しは **stem の完全一致**だけ (添字・番号は使わない)。stem が同一の問題が複数あるとき (読解の指示文・「次の英文のうち正しいものを選びなさい。」型など) は `passage` または `choices` (4 つの選択肢の配列) も書いて 1 問に絞る。
- 指摘が無ければ空配列 `[]` を保存する。問題がないものは書かない。
- 報告は 3 行以内 (drop 件数・fix_expl 件数・最も重要な指摘 1 つ)。問題本文は報告に貼らない。
