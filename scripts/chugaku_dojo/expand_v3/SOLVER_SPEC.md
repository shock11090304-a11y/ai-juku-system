# 盲検 (独立解答) の仕様 — 解答エージェントが読む正典

対象: `scripts/chugaku_dojo/expand_v3/blind/batch_<part>_<n>.json` (JSON 配列。各要素 `{id, stem, passage, choices}`。正解・解説は入っていない)。
あなたは作問者とは別人です。**出題意図を推測せず、自分で解いて**答えを決めてください。

## 出力
`scripts/chugaku_dojo/expand_v3/blind/ans_<part>_<lens>_<n>.json` に、JSON 配列のみを Write ツールで保存:
```json
[{"id":"eng4-07","answer_text":"heavier","answer_index":0,"confident":true}, ...]
```
- `answer_text` は選んだ選択肢の**本文をそのまま** (1 文字も変えずコピー)。`answer_index` はその 0 始まりの位置。両方書く。
- `confident` は「正解がこれ 1 つに定まる」と確信できるとき true。2 つ正解に見える・どれも正しくない・条件不足・曖昧、のときは false (答えは最も妥当なものを書く)。
- 全要素ぶん必ず出す (飛ばさない)。本文・理由は書かない。保存後の報告は 2 行以内 (件数と confident=false の件数)。

## レンズ (指示された 1 つだけ)
- **A 自力解答**: 問題を最初から最後まで自分で解き、答えを出してから選択肢を見る。計算問題は途中の値まで出す。
- **B 全肢点検**: 4 つの選択肢を 1 つずつ空所や条件に当てはめて全文・全ケースを作り、「正しい」「誤り」を個別に判定する。正しいものが 2 つ以上・0 のときは confident=false。英語は、口語で広く許容される形も「正しい」と数える (作問者の意図ではなく英語として成立するか)。
- **C 別経路**: 英語は「ネイティブが自然に使うか」「文脈上あり得るか」の観点で。数学は Bash で python3 を実行し、実際に計算・全列挙・方程式の解で確定する (計算できない設問は confident=false)。理科・社会・国語は年号・人名・制度・数値・語義・法則・活用など事実を、少しでも不確かなら WebSearch で裏取りしてから選ぶ (裏取りできないときは confident=false)。
- 読解 (passage が空でない): 本文に書いてあることだけを根拠にする。本文外の知識で判断しない。
