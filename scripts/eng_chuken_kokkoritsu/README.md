# 地方国公立・中堅大 英文法 実戦問題集

『難関国公立大 英文法 実戦問題集』（`../eng_kokkoritsu_nankan/`）の一段手前。
偏差値50〜57帯（地方国公立・中堅私大）向けで、四択から記述へ橋渡しする。
第3部を8割取れたら難関編の第1部へ進める設計。

## 使い方（機械は姉妹編と共有。このディレクトリにはデータしか無い）

```bash
WORKBOOK_DIR=scripts/eng_chuken_kokkoritsu python3 scripts/eng_kokkoritsu_nankan/check.py
WORKBOOK_DIR=scripts/eng_chuken_kokkoritsu python3 scripts/eng_kokkoritsu_nankan/build.py
WORKBOOK_DIR=scripts/eng_chuken_kokkoritsu python3 scripts/eng_kokkoritsu_nankan/blind.py make <出力先>
```

組版・機械ゲート・盲検証ハーネスは**コピーせず**姉妹編のものを使う。
`WORKBOOK_DIR` を付けるとそちらの `content.py` を読む。付けなければ難関編が動く。
3冊目を作るときも `content_p1/p2/p3.py` と `content.py` を書くだけでよい。

## ★四択を入れたことで出た、この冊子固有の罠

- **正解位置は手で振ると必ず偏る**。初版は34問中19問が2番だった。
  `content.py` の `_balance_mc()` が stem の md5 順で機械的に散らす（結果 9/9/8/8）。
  解説が①②③④を参照していないことが前提なので、参照を書かないこと。
- **正解肢が単独で最長になる**（`whether` vs `that/what/which` など）。
  長さだけで当てられるので、選択肢の文字数をそろえる。
  ★ただし**同点は tell ではない**。機能語1語どうしは長さが並ぶのが普通で、
  共通ゲートの `longest_tell`（同点も最長と数える）をそのまま使うと誤検出する。
  `check.py` 側で「単独で最長」に絞って判定している。
- **長さを揃えるために足した誤答肢が、それ自体成立してしまう**。
  実際に `and it` を足したら文法的に通ってしまい第2正解になった（→ `and which` に）。
  誤答肢を足したら必ず「なぜ成立しないか」を一つずつ言えるか確認する。

## ★二冊とも同じ形で踏んだ最大の罠

**修正が新しい欠陥を生む。** 直したら必ず盲で読み直すこと。

| 何を直したか | 何が壊れたか |
|---|---|
| 語数を合わせるために語を足した | 二重否定の片方が落ちて**日本語と意味が正反対**になった |
| 正解肢が最長になる tell を潰した | 足した誤答肢が成立して第2正解になった |
| 別解が出る整序を差し替えた | 第1部と同じ知識で解ける易しさになった（難度の逆転） |
| 下線部の長さを揃えた（難関編） | 時制が破綻した（`in recent years` と現在形の衝突） |

機械ゲートは「トークンと解答の語が一致するか」は見るが、
**日本語と英語の意味が合っているかは測れない**。ここは盲ソルバーにしか出せない層。
