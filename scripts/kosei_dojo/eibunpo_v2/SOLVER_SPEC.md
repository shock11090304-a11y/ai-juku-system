# 盲検 (独立解答) の仕様 — 解答エージェントが読む正典

対象: `scripts/kosei_dojo/eibunpo_v2/blind/batch_<part>_<n>.json` (JSON 配列。各要素 `{id, stem, passage, choices}`。正解・解説は入っていない)。
高校英文法 (定期テスト〜入試基礎) の 4 択です。あなたは作問者とは別人です。**出題意図を推測せず、その英文が英語として正しく成立するかだけで**答えを決めてください。

## 出力
`scripts/kosei_dojo/eibunpo_v2/blind/ans_<part>_<lens>_<n>.json` に、JSON 配列のみを Write ツールで保存:
```json
[{"id":"r_grammar5-07","answer_text":"must have been","answer_index":0,"confident":true}, ...]
```
- `answer_text` は選んだ選択肢の**本文をそのまま** (1 文字も変えずコピー)。`answer_index` はその 0 始まりの位置。両方書く。
- `confident` は「正解がこれ 1 つに定まる」と確信できるとき true。2 つ以上が英語として成立する・どれも成立しない・文脈不足で決まらない・口語では別の形も許容される、のときは false (答えは最も妥当なものを書く)。
- 全要素ぶん必ず出す (飛ばさない)。本文・理由は書かない。保存後の報告は 2 行以内 (件数と confident=false の件数)。

## レンズ (指示された 1 つだけ)
- **A 自力解答**: 設問を読み、選択肢を見る前に空所に入る形を自分で決め、それに一致する選択肢を選ぶ。
- **B 全肢点検**: 4 つの選択肢を 1 つずつ空所に入れた全文を作り、「文法的に正しく、その文脈で意味が成り立つか」を個別に判定する。正しいものが 2 つ以上・0 のときは confident=false。**口語・米英の差で広く許容される形も「正しい」と数える** (作問者の意図ではなく英語として成立するか)。正誤問題は 4 文すべてを個別に判定する。
- **C 別経路**: 文法書・辞書の目で確かめる。語法 (自動詞/他動詞・動詞がとる前置詞・不定詞か動名詞か・可算/不可算・慣用表現) は少しでも不確かなら WebSearch (Cambridge / Oxford / Merriam-Webster / Longman などの辞書サイト) で裏取りしてから選ぶ。裏取りできない・辞書で両方の形が載っている、のときは confident=false。
