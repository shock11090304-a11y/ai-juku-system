# 独立レビューの仕様 — レビューエージェントが読む正典

対象: `scripts/kosei_dojo/eibunpo_v2/verified/<part>__<gi>.json` (指示されたファイル群)。各要素 `{subject, part, filter, unit, stem, passage, choices, answer_index, explanation, form, level}`。
これらは盲検 3 名が全員正解した高校英文法の問題です。盲検では見えない欠点だけを探してください。

## 見るもの (指示されたレンズ)
- **R1 重複と範囲**: (a) 「名前・語を替えただけの同じ文」「同じ論点を同じ文型で問う問題」が同じカード内・渡されたファイル間・既存プール (`blind/stems_<part>.json`) にないか → 後ろの方を drop。別の例文で同じ文法項目を練習するのは反復であって重複ではない (ほぼ同一の文・同一の正解語+同一の文構造だけを潰す。同じ正解語は 1 カード 3 問まで)。(b) 高校 1〜2 年の標準文法 (定期テスト〜入試基礎) より明らかに難しい (難関大の稀な語法・文学的な倒置・専門語彙) または中学レベルで単純すぎる → drop。(c) 設問文・選択肢に他カードの名前 (渡される一覧) が混ざっている → drop。解説に多いときは fix_expl で減らす。(d) `unit` の細目が問うている論点と合っていない → fix_unit (`unit_new` に正しい `<tag>(<細目>)`)。
- **R2 癖と解説**: (a) 読まずに当たる: 正解だけ長い／詳しい、形が 1 つだけ違う選択肢 (= 必ず誤答)、設問文の空所の外に正解の語がそのまま書いてある、正誤問題で正しい文だけ構造が違う → drop。(b) 正解が実は 2 つある (口語・米英の差で許容される形を含む)・正解が誤っている (盲検を通っても起こる) → drop (理由に自分の答えを書く)。語法は WebSearch で辞書を引いて確かめてよい。(c) 解説の誤り: 「〜という形は無い」「必ず〜」の誤った断定、文法用語の誤用、正解の根拠になっていない、誤答の説明が今の選択肢に無い語を指している → fix_expl (解説全文を書き直し、必ず正解の選択肢の本文を含める。位置語 ア/A/①/N 番目 は禁止)。
- **R3 生徒の画面の目**: (a) 英文が不自然・意味が通らない・文脈と答えが矛盾 → drop。(b) 日本語ヒントが無いと 1 つに決まらない、またはヒントが答えをそのまま言っている → fix_stem (`stem_new`。正解の本文は変えない) か drop。(c) 空所が 2 か所・`___`・記号の崩れ・不要な全角英数字 → fix_stem。(d) 解説が高校生に伝わらない (専門用語だけ・根拠が書かれていない) → fix_expl。

## 出力
`scripts/kosei_dojo/eibunpo_v2/blind/review_<part>_<R1|R2|R3>.json` に JSON 配列のみを Write ツールで保存:
```json
[{"stem":"<問題文を 1 文字も変えずにコピー>", "action":"drop", "reason":"同じ枠: 助動詞 must have+過去分詞 の空所で主語だけ違う"},
 {"stem":"<問題文>", "action":"fix_expl", "reason":"解説の『need は不定詞を続けられない』は誤り", "explanation":"【単元】助動詞(need の用法)。正解は「need not」。…"},
 {"stem":"<問題文>", "action":"fix_unit", "reason":"細目が論点と違う", "unit_new":"仮定法(if の省略・倒置)"},
 {"stem":"<問題文>", "action":"fix_stem", "reason":"日本語ヒントが答えをそのまま言っている", "stem_new":"…"}]
```
- 指し示しは **stem の完全一致**だけ (添字・番号は使わない)。stem が同一の問題が複数あるとき (正誤問題の指示文など) は `choices` (4 つの選択肢の配列) も書いて 1 問に絞る。
- 指摘が無ければ空配列 `[]` を保存する。問題がないものは書かない。
- 報告は 3 行以内 (drop 件数・fix 件数・最も重要な指摘 1 つ)。問題本文は報告に貼らない。
