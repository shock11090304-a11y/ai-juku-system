# 入試問題道場「単元別（弱点克服）」英文法 13 カード 増量 v2 — 作問仕様 (作問エージェントが読む正典)

対象: **高校英文法・定期テスト〜大学入試基礎** (高1〜高2 の文法参考書 (Vision Quest / be / Forest 相当) の範囲。共通テスト・私大基礎で出る標準事項まで。難関大の稀な語法・文学的表現は出さない)。
1 カード **42 問**。出力は JSON 配列。1 問 = 次のオブジェクト (キー名・型は厳守):

```json
{"subject":"英語","part":"r_grammar","filter":"助動詞","unit":"助動詞(must have+過去分詞・過去の推量)",
 "stem":"Aya fell asleep as soon as she got home. She ( ) very tired after the long trip.",
 "passage":"", "choices":["must have been","must be","should have been","cannot have been"], "answer_index":0,
 "explanation":"【単元】助動詞(must have+過去分詞・過去の推量)。正解は「must have been」。帰宅してすぐ眠ったという過去の事実から、過去のことを推量する must have + 過去分詞「〜だったにちがいない」が合う。must be は現在の推量で、過去の文脈に合わない。should have been は「〜であるべきだった (のに違った)」の非難・後悔で、事実と逆になる。cannot have been は「〜だったはずがない」で、眠った事実と矛盾する。",
 "form":"空所補充", "level":"標準"}
```
- `part`・`filter` は指示されたものと**完全一致**。`passage` は常に `""`。
- `unit` は **`<tag>(<細目>)`** の形。`<tag>` は指示されたカードのタグ (関係詞 / 仮定法 / 時制 / 比較 / 分詞 / 助動詞 / 受動態 / 不定詞 / 動名詞 / 接続詞 / 前置詞 / 語法 / 倒置・強調) を 1 文字も変えずに書く。`<細目>` は問う論点を 25 文字以内で具体的に (入れ子のかっこは使わない)。
  **同じ細目は 2 問まで**。渡される `syllabus` (覆うべき細目の目安) を**偏りなく** 20 細目以上カバーし、`existing_subtopics` (既存プールに多い細目) は別の角度・別の文で扱う。
- `answer_index` は 0 始まり。`choices` は 4 つとも**相異なる**文字列 (大文字小文字だけの違いは不可)。
- `form` は 空所補充 / 語形選択 / 対話応答 / 書きかえ / 正誤 のどれか。**空所補充が 6 割以上**。並べかえ (語順を番号で問う形) は使わない。
  - 空所補充: 英文 1 文 (8〜16 語) に空所 `( )` を **1 か所**。`___` は使わない。
  - 語形選択: 空所 1 か所で、選択肢は同じ語の活用・形 (go / went / gone / going など)。
  - 対話応答: `A: … B: …` の 2 行で空所 1 か所 (改行は `\n`)。
  - 書きかえ: 元の文を示し、`= ` で始まる同意文の空所 1 か所を問う (改行は `\n`)。
  - 正誤: 「次のうち文法的に正しい文を選びなさい。」または「…誤りを含む文を選びなさい。」と設問文で明示し、選択肢は 4 つの英文 (長さをそろえる)。1 カードで 6 問まで。
- `level` は 基礎 / 標準 / やや応用。配分の目安 3 : 5 : 2。
- 空所の答えが文脈だけでは 1 つに定まらないとき (助動詞のニュアンス・時制の選択など) は、英文の後に **日本語の意味を「」で 1 つ** 添える (例: `You ( ) see a doctor right away. 「〜したほうがよい」`)。42 問のうち日本語ヒント付きは 3 割まで。

## 1. 正解の一意性 (最重要・盲検 3 名が全員一致した問題しか採用されない)
- **4 つの選択肢をすべて空所に入れた全文を自分で作り**、誤答 3 つが「文法的に誤り」または「その文脈では意味が成り立たない」ことを確かめる。「やや不自然」「あまり言わない」程度の誤答は使わない。
- **口語・米英の差で広く許容される形は正解として数える** (例: will と would、since と because、must と have to、if 節の were と was、関係代名詞 that と which、前置詞 at/in の揺れ、過去形と現在完了の揺れ)。2 つ以上が許容される問題は作らない。文脈 (時を表す語・文の後半・前後関係) で 1 つに絞る。
- 誤答は高校生が実際にやる典型ミス (時制・態・不定詞と動名詞・自他動詞・前置詞の取り違え・活用形) にする。荒唐無稽な選択肢は不可。
- 設問文で問う文法事項と答えの根拠が英文の中に**書かれている**こと (時を表す副詞・後続の than・前置詞など)。外部知識や作問者の意図を推測しないと解けない問題は不可。

## 2. 「読まずに当たる」選択肢を作らない (盲検では見つからないので作問時に守る)
1. **長さ・具体性をそろえる**: 正解だけ長い／短い／詳しい、を作らない。4 つを同じくらいの語数・字数で。
2. **形をそろえる**: 4 つの品詞・形・時制の種類をそろえる (助動詞の問題なら 4 つとも助動詞句、関係詞なら 4 つとも関係詞)。「形が 1 つだけ違う選択肢」は必ず誤答に見えてしまう。「to +原形」が 1 つだけ、-ing が 1 つだけ、は不可。
3. **正解の形を偏らせない**: カード全体で「答えはいつも -ing」「いつも過去分詞」「いつも最上級」にならないよう混ぜる。
4. **設問文に正解の語をそのまま書かない** (空所の外に正解と同じ語があるのは不可。誤答にある語が設問文にあるのは可)。
5. 複合選択肢 (A・B の 2 要素) は 2×2 にし、どちらの要素でも正解の値が単独最多にならないようにする。
6. 正誤問題では、正しい文だけ短い／長い、を作らない。4 文とも同じ構造・同じ長さ帯にする。

## 3. 解説 (`explanation`)
- 必ず `【単元】<unit>。正解は「<正解の選択肢の文字列そのまま>」。` で始める (正解テキストの末尾が `.` `?` なら「。」を重ねない)。
- 続けて 2〜4 文 (120〜220 字): (a) 正解の根拠 = 英文中のどの語・文脈から決まるか、(b) 誤答 3 つがそれぞれなぜ誤りか (短く)。既存プールと同じ丁寧さ。
- **位置語 (ア/イ・A/B・①②・「2 番目の選択肢」) は stem にも explanation にも絶対に書かない** (選択肢は後で入れ替わる)。選択肢は必ず本文で指す。
- **「〜という形は無い」「〜は必ず〜」のような断定は、本当に例外が無いときだけ**書く (盲検後の校閲で最も多く直された誤り)。
- 設問文・選択肢に**他カードの名前 (渡される「避ける語」) を書かない**。解説でも避けられる限り避ける (配信 API が全文をカード名で検索するため、他カード名が多いと配信枚数の予算を食う)。文法用語として避けられないとき (動名詞の解説で「不定詞」など) だけ 1 回まで。

## 4. 重複の回避
- 渡される `stems_<part>.json[filter]` (道場の既存問題文) と `drill_stems_<part>.json[filter]` (単元ドリルの既存問題文) を読み、**同じ文・名前や語を 1 つ替えただけの文を作らない**。文脈 (学校・家庭・旅行・仕事・ニュース・科学・歴史・スポーツ・買い物・健康・環境…) と人名を散らす。
- 自分の 42 問の中でも同じ文型の使い回しをしない。同じ正解語 (例: which) は 3 問まで。

## 5. 表記
- 人名は多様に (Aya, Daiki, Mika, Ryo, Sora, Haru, Emma, Liam, Noah, Olivia, Mr. Brown, Ms. Lee …)。Tom / Ken / Mary に偏らせない。実在の人物・企業・作品は出さない。
- 英文は自然で現代的な標準英語。縦棒・記号・HTML・下線は使わない。空所は半角 `( )` (中は空白 1 つ)。アポストロフィは `'`。
- 日本語は常用の表記。全角かっこ「」は日本語ヒント・引用にだけ使う。

`scripts/kosei_dojo/eibunpo_v2/drafts/<part>__<gi>.json` に **JSON 配列のみ** を Write ツールで保存する (前置きの文章やコードフェンスは入れない)。保存後、件数と `form` の内訳だけを 3 行以内で報告する。
