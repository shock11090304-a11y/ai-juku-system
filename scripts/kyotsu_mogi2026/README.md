# 共通テスト模試 2026 (英語・数学)

大学受験生向けの共通テスト形式 模試問題。`mock-exam.html` の「画面で受験する模試 (AI採点)」から
そのまま出題される `exam_questions` プールに投入する。

## 何がどこに入るか

| 模試テンプレ (`MOCK_EXAM_TEMPLATES`) | セクション | プール枠 `(exam_id, part_key, eiken_grade)` | 今回の追加 |
|---|---|---|---|
| `kyotsu` 共通テスト英語 (リーディング相当) | 短文読解 | `(daigaku, r_short, kyotsu)` | 4 大問 / 17 小問 |
| | 長文読解 | `(daigaku, r_long, kyotsu)` | 5 大問 / 25 小問 |
| `kyotsu_math` 共通テスト 数学 (IA・IIB) | 数学I・A | `(rikei, math_1a, kyotsu_rikei)` | 6 大問 / 30 小問 |
| | 数学II・B | `(rikei, math_2b, kyotsu_rikei)` | 6 大問 / 30 小問 |

合計 **21 大問 / 102 小問**。テンプレが 1 回に引くのは英語 2+3 大問・数学 3+3 大問なので、
この追加分だけでも毎回違う組み合わせの模試が成立する (既存プールとも合算される)。

全小問が `multiple_choice` なので `mock_exam_submit` の自動採点に載り、
小問ごとの `unit` タグが `question_attempts` に落ちて弱点分析・単元ドリル推薦につながる。

## 手順

```bash
# 1. 生成 (検証込み・失敗したら非ゼロ終了して JSON を書かない)
python3 scripts/kyotsu_mogi2026/build_eng.py
python3 scripts/kyotsu_mogi2026/build_math.py   # 要 sympy

# 2. 取込前チェック (server/main.py の実定義と突き合わせ)
python3 scripts/kyotsu_mogi2026/preflight.py

# 3. 本番投入 (CRON_SECRET は環境変数から)
railway run -s ai-juku-api python3 scripts/kyotsu_mogi2026/import_prod.py
```

`import_prod.py` は `--dry-run` で件数だけ確認できる。`eng` / `math` を引数に取ると片方だけ投入する。

## 品質ゲート

**数学** — 正解を手で書かない。各小問は `correct` / `distractors` を「LaTeX と sympy 値」の組で持ち、
`verify()` が別の道筋で独立に再計算する。両者が一致しなければ `build_math.py` は JSON を書かずに落ちる。
60 小問すべてがこの照合を通っている。誤答も sympy で正解と同値でないことを確認済み
(別表記の同一値がまぎれ込むと「正解が 2 つある問題」になるため)。

**英語** — `scripts/eng_kyotsu_2026/validate_and_build.py` と同じゲートを `build_eng.py` に実装。
解説が `正解は「<正答の選択肢テキスト>」。` で始まり本文と完全一致すること、選択肢の重複がないこと、
HTML エンティティが残っていないこと、図依存表現 (`the figure above` 等) を含まないことを検査する。
本文中の表はすべて文字だけで組んであり、画像なしで解答できる。

**共通** — 正解位置は md5 順の round-robin で 0〜3 に完全均等配分 (英語 11/11/10/10、数学 15/15/15/15)。
ハッシュの剰余だけだと実測で 11/19/15/15 まで偏り、当てずっぽうが有利になるため順位で割り当てている。

**preflight.py** — `server/main.py` を実際にパースして次を確認する。

1. `(exam_id, part_key, eiken_grade)` が `EXAM_QUESTION_ROTATION` にあるか (無いと全行 `invalid rotation`)
2. `MOCK_EXAM_TEMPLATES` の該当模試が必要な大問数を引けるか
3. 自己完結ゲート Layer A (`_self_containment_gate`) に掛からないか (掛かると黙って捨てられる)
4. `mock_exam_generate` / `mock_exam_submit` の採点式を再現し、全問正解が 100% になるか

## 注意

- `import_prod.py` は同一プールかつ `question_data` 完全一致を `skipped_dup` で弾くので、二重実行しても重複しない。
- 問題文・設問はすべて新規に書き起こしたもので、実在の試験問題の転載ではない。
  英語の伝記大問に登場する人物は模試用に作った架空の人物。
