## 1. ★ 数値を答えさせるときの 2 つの門

神テストの自動採点は完全一致 (共通編 §4)。理科は数値の答えが多いので、
ここが最初にぶつかる壁になる。

| 書き方 | 判定 |
|---|---|
| `short` で `"50"` | ✗ **取り込みが弾く** (「記述の正解が数字だけです。選択式にするつもりではありませんか」) |
| `short` で `"50Ω"` | ○ 単位を付ければ通る |
| `short` で `"0.30g"` | ○ **有効数字も一致させる**。生徒が `0.3g` と書くと不正解になるので `accepted_answers` に入れる |

★ **解答欄に単位を刷ってはいけない** (build が落とす)。紙に「解答欄 ___ A」と
刷ると生徒は数字だけ書くのに、画面には単位つきで打つ必要がある、という食い違いに
なる。答え方は**設問文に書く** —「単位をつけて答えよ (例: 12A)」。
数値+単位の正解なのに設問文に答え方が無ければ build が落とす。
| `choice` で 4 択 | ○ **迷ったらこれ**。桁を 1 つずらした誤答・単位だけ違う誤答が作れる |

### 単位の規則 (紙の問題集で何度も落ちた項目)

- **解答欄に刷る単位と、`correct_answer` の単位を一致させる。**
  「答 ___ g」の欄に `"0.30"` だけ入れず `"0.30g"` と書く
- `"50A"` と `"50Ω"` のような取り違えは機械では気づけない。**設問文・解答欄・正解の
  3 か所で同じ単位になっているか**を 1 問ずつ目で見る
- 単位の書き方の揺れは全部 `accepted_answers` に:
  `"50Ω"` に対して `"50 Ω"` `"50オーム"` `"50ohm"`

### 有効数字

- **設問文に必ず書く。**「四捨五入して小数第 2 位まで答えよ」「有効数字 2 桁」
- 書かないと `0.3` / `0.30` / `0.300` が全部出てきて、どれを正解にしても
  正しく解いた生徒が不正解になる

## 2. 図・グラフ・実験装置

- **図は PDF にしか置けない。** 画面に出るのは「第N問」と数字ボタンだけ (共通編 §0)。
  理科は図が無いと設問が成立しないことが多いので、**PDF が本体**だと考える
- 実験の前提条件 (温度・圧力・「摩擦は無視する」「気体は理想気体とみなす」) は
  **図の中ではなく本文 (intro) に書く**。図だけにある条件は読み落とされる
- 線と文字は `currentColor`、塗りは中間色 (#3b82f6 / #ef4444 / #22c55e / #f59e0b)
- **✓ / ✗ は文字で置かず線で描く** (日本語フォントに無いと PDF で豆腐になる)
- グラフの軸には**単位を必ず入れる**。目盛りの数値は設問の根拠になるので、
  設問文にも同じ数値を書いておく (PDF の印刷で読めなくなっても設問が壊れない)

## 3. ★ 解答漏洩 — 理科で一番多い事故

**第N問の答えが、同じ冊子の別のどこかに印字されていないか。**
走査対象は「他の設問文・実験の説明・図表の中の語・他の設問の選択肢」の全部。

例:

- (3) の答えを「中和」にしたのに、(7) の設問文に「中和滴定では…」と書いた
- 大問の説明文に「この気体は二酸化炭素である」と書いたのに、
  小問で「発生した気体は何か」と聞いた
- グラフの凡例に「(蒸発)」と書いてあり、それが答えだった

→ **答えの語 (2 字以上) で冊子の全文を検索する**。1 問ずつやる。
これは紙の問題集のゲート (`scripts/_workbook_check.py`) が実際に落としている項目で、
神テストの冊子にはまだ同じ検査が無い (§6)。

## 4. 解説の形

英語の 4 セクションは `subject == "grammar"` 専用。理科は次の形に統一する
(見出しは `## ` ではなく **【】**。素のテキストで表示されるため — 共通編 §5):

<!-- canon:headings -->
```
【何が起きているか】現象を 1〜2 行。図のどこを見るかも言う。
【使う法則】オームの法則 / 質量保存 / 浸透圧 — 名前を出す。
【立式】文字で置いて、数値を入れる前の式を出す。
【計算】単位を付けたまま計算する。有効数字の処理も見せる。
【誤答の切り方】1. …— 桁が 1 つ違う / 単位が違う / 逆向きに読んだ。
```
<!-- /canon:headings -->

**5 つが順番どおりに 1 回ずつ。1 つでも欠けたら build が落ちる。**
★ **記述 (`short`) の設問では【誤答の切り方】は書かなくてよい** — 選択肢が無いので誤答も無い。書いてもよい (書けば順番だけ見る)。

- 化学式は **解説では素の記法** (`H2O` `Ca(OH)2` `2H2 + O2 → 2H2O`)。
  下付きの Unicode 文字 (`H₂O`) は**フォントによって PDF で豆腐になる**ので使わない。
  PDF 側は組版で `<sub>` を使って下付きにする
- 単位付きの数値は**必ず単位ごと書く**。「50」ではなく「50Ω」
- 誤答は「なぜその値が出てしまうか」まで書く (「直列と並列を取り違えると 12Ω になる」)

## 5. 冊子の標準仕様 (最初の 1 冊はこの形で)

| 項目 | 値 |
|---|---|
| 問数 | 10 問 (単元別ドリル) / 大問 3〜4 本 20 問 (総合) |
| 形式 | 4 択が主力。用語と単位付きの数値だけ `short` |
| 配点 | 1 問 2〜3 点。合計 20〜50 点 |
| 制限時間 | 単元別 25 分 / 総合 50〜60 分 |
| `subject` | `science` |
| 単元タグ | `BUTSURI-…` (物理) / `KAGAKU-…` (化学) / `SEIBUTSU-…` (生物) |
| ディレクトリ | `scripts/book_exam/materials/〈ローマ字〉/` (例 `rika_denki1`) |

★ **1 冊に物理と化学を混ぜない。** `subject` はどちらも `science` なので、
**題名だけが唯一の区別**になる (「物理 電気回路 演習 第1集」)。

★ **範囲を超えない。** 中学向けの冊子に高校内容 (モル計算・対数・イオン化傾向の詳細) を
入れない。題名と `level` で対象を宣言し、その範囲で閉じる。

## 6. 機械が見るもの / 見ないもの

**見る** (build 時 `_book_build.verify()`、コミット済み JSON は `check_grammar_books.py`):

- 番号・ページ・配点・単元タグ・正解の形 (記述の正解が数字だけ、なども)
- 解説 5 見出しの欠けと順番 / 誤答の節の番号と選択肢のずれ
- 正解位置の偏りと 3 連続
- 解説に生の LaTeX が混じっていないか
- **記述の正解が問題編の別の場所に印字されていないか (解答漏洩)**
- **刷り上がり PDF に全問・全選択肢が正典どおりのページに在るか**

**見ない** (共通編 §7 の③層。人が全問読むしかない):

- **選択肢の中に答えが漏れていないか**。解答漏洩の検査は記述 (`short`) の
  正解だけを見る。選択式の「正解の語が他の設問文に出ている」は見ていない
- **単位と有効数字の整合** (§1)。紙の問題集側の `scripts/_workbook_check.py` には
  単位一致の検査がある。神テスト向けに移植したら `check_grammar_books.py` の
  `subject` 分岐に足し、**必ずコミットする**
- **正解の一意性** (§7)
- 正解肢だけが最長になっていないか (テル)

---

## 7. 内容の質 (機械では測れないので自分で守る)

- **誤答肢が正解になっていないか。** 4 択は「4 つとも、資料や定義で真偽を判定できる」形に
- **正解肢だけ長くしない。** 長い肢が正解、という形のテルは生徒がすぐ見抜く
- **同じ論点を 2 回聞かない** (単元別 10 問なら 10 の論点)
- 生物のカタカナ用語は表記が揺れる (`ミトコンドリア` / `ミトコンドリアー`)。
  `short` にするなら `accepted_answers` を厚くする。迷ったら 4 択
- 物理は**向きの取り方を設問文で固定する** (「右向きを正とする」)。
  固定しないと符号違いの答えが両方正しくなる

## 8. 理科で落ちやすいところ

| 症状 | 原因 / 対策 |
|---|---|
| 取り込みが「記述の正解が数字だけです」で止まる | §1。単位を付けるか 4 択にする |
| 正しい値を書いた生徒が不正解 | 有効数字か単位の表記揺れ (§1) |
| 答えが冊子のどこかに書いてある | 解答漏洩 (§3)。答えの語で全文検索する |
| 解説の `H₂O` が PDF で豆腐 | 下付き Unicode を使った (§4) |
| 符号違いの答えが両方正しい | 向きを固定していない (§7) |
| 図の数値が読めず設問が解けない | 根拠の数値を設問文にも書く (§2) |
