## 1. ★ 社会だけが持つ最大の問題 — 事実が年で入れ替わる

「日本の最大の貿易相手国」「世界の人口 1 位」「食料自給率」— **数年で変わる**。
冊子は一度作ると何年も配られるので、作った瞬間に古くなる設問を作ってはいけない。

規則:

1. **順位そのものは原則として出題しない。**
   「第 1 位はどこか」ではなく「**この資料から読み取れることとして正しいものはどれか**」
2. 数値を含む事実 (統計・シェア・順位) を使うなら、**一次情報を確認する**。
   総務省統計局・外務省・国連・IMF など、出典に当たる。二次情報の孫引きをしない
3. **出典と年次を `build_*.py` の冒頭コメントに書く。**

   ```python
   """神テスト 教材「地理 貿易と資源 演習 第1集」— 問題 PDF と取り込み JSON を作る。

   出典: 財務省貿易統計 2025 年確報 (2026-03 公表)。§3 の表はここから引いた。
   ★ この冊子は 2025 年のデータに依存する。2 年ごとに数値を見直すこと。
   """
   ```
4. 冊子の**表紙 (1 ページ目) に基準年を刷る**。「統計は 2025 年時点」
5. 変わらない事実で出題できないか先に考える。
   地形・気候区分・条約の成立年・制度の仕組みは動かない

## 2. 資料 (地図・グラフ・年表・統計表)

- **資料は PDF にしか置けない。** 画面に出るのは「第N問」と数字ボタンだけ (共通編 §0)。
  社会は資料読み取りが主力なので、**PDF が本体**
- 資料の**出典と年次を資料の下に刷る**。本番の入試もそうなっている
- 資料の数値のうち**設問の根拠になるものは設問文にも書く** (印刷で潰れても設問が壊れない)
- 白地図を使うなら**方位と縮尺**を入れる
- 線と文字は `currentColor`、塗りは中間色 (#3b82f6 / #ef4444 / #22c55e / #f59e0b)
- **✓ / ✗ は文字で置かず線で描く** (日本語フォントに無いと PDF で豆腐になる)

### 著作権

地図・写真・統計グラフを他所から持ってこない。**このリポジトリは PUBLIC** で、
冊子 PDF はコミットされる (共通編 §8)。数値から**自分で描く**。
政府統計の数値そのものに著作権は無いが、**作図されたグラフには著作権がある**。

## 3. 解答形式 — 年号は `short` に直接入れられない

採点は完全一致 (共通編 §4)。

| 答えさせるもの | 形式 | 注意 |
|---|---|---|
| 年号 | `short` | ★ **`"701"` は弾かれる (数字だけ)。`"701年"` と書く** |
| 人名・地名・制度名 | `short` ○ | 表記揺れを `accepted_answers` に厚く |
| 出来事の順序 | **4 択** | 並べ替えは選択肢にして出す |
| 資料の読み取り | **4 択** | |
| 記述 (理由説明) | ✗ 自動採点しない | PDF に手書き欄を刷る (共通編 §4) |

### 表記揺れの潰し方 (`accepted_answers`)

社会は用語の書き方が最も割れる教科。**書きそうな形を全部入れる**:

- `"大宝律令"` → `"たいほうりつりょう"` `"大宝律令(701年)"` は入れない (別物)
- `"アメリカ合衆国"` → `"アメリカ"` `"米国"` `"アメリカ合衆国"`
- `"リアス海岸"` → `"リアス式海岸"` (教科書によって呼び方が違う)
- 漢字が書けない生徒のために**かな表記も入れるか**は方針を決めて冊子内で統一する
  (漢字を書かせたいなら入れない。用語を知っているかを見たいなら入れる)

★ 決めたら `build_*.py` の冒頭コメントに書く。冊子ごとにぶれると生徒が混乱する。

## 4. ★ 中立性 — 事実を問い、立場を問わない

- 論争のある政治的・社会的論点は、**制度の仕組みと事実関係だけを問う**。
  「◯◯政策は正しいか」を 4 択にしない
- 資料読み取りの正解は「**この資料から読み取れること**」に限る。
  資料を超えた価値判断を正解にしない
- 特定の団体・政党・国について、資料の裏付けなしに評価する選択肢を作らない
- 公民の制度は**改正される**。施行年と、必要なら条文番号を設問文に書く

## 5. 解説の形

英語の 4 セクションは `subject == "grammar"` 専用。社会は次の形に統一する
(見出しは `## ` ではなく **【】**。素のテキストで表示されるため — 共通編 §5):

<!-- canon:headings -->
```
【何を問うているか】資料読み取り / 用語 / 因果 — 型を名乗る。
【資料のどこ】表の 2010 年の行、グラフの右端 — 見る場所を指す。
【正解の理由】資料の値と選択肢の言い分がどう対応するかを言う。
【誤答の切り方】1. …— 資料に無い / 年次が違う / 因果が逆 / 主体が違う。
【覚え方の目印】年代の語呂・地図上の位置・制度の対になる語を 1 行。
```
<!-- /canon:headings -->

**5 つが順番どおりに 1 回ずつ。1 つでも欠けたら build が落ちる。**
★ **記述 (`short`) の設問では【誤答の切り方】は書かなくてよい** — 選択肢が無いので誤答も無い。書いてもよい (書けば順番だけ見る)。

- **資料からの引用は数値も語も一字一句そのまま。** 要約を「」で囲まない
- 誤答は型の名前で切る (「資料に無い」「年次が違う」「因果が逆」「主体が違う」)
- 年代を扱うときは**世紀と西暦を両方書く** (「8 世紀初め (701年)」)

## 7. 機械が見るもの / 見ないもの

**見る** (build 時 `_book_build.verify()`、コミット済み JSON は `check_grammar_books.py`):

- 番号・ページ・配点・単元タグ・正解の形 (記述の正解が数字だけ、なども)
- 解説 5 見出しの欠けと順番 / 誤答の節の番号と選択肢のずれ
- 正解位置の偏りと 3 連続
- 解説に生の LaTeX が混じっていないか
- **記述の正解が問題編の別の場所に印字されていないか (解答漏洩)**
- **刷り上がり PDF に全問・全選択肢が正典どおりのページに在るか**

**見ない** (共通編 §7 の③層。人が全問読むしかない):

- **選択式の解答漏洩**。漏洩の検査は記述 (`short`) の正解だけを見る。
  「正解の語が資料の凡例に出ている」は見ていない。
  ★ 1 冊目では資料の表を（ A ）（ B ）の**空欄**にして、資料を読むだけで
  答えが出ないようにした。資料読み取りの設問を作るときはこの形にする
- **基準年の宣言**。統計を使う冊子の `build_*.py` 冒頭に出典と年次のコメントが
  あるかは、まだ機械で見ていない
- **事実が古くなっていないか** (§1)。これは機械には原理的に見えない
- **中立性** (§4) と **正解の一意性**

→ 上の 2 つは検査を書ける。書いたら `check_grammar_books.py` の `subject` 分岐に足し、
**必ずコミットする**。

## 8. 社会で落ちやすいところ

| 症状 | 原因 / 対策 |
|---|---|
| 取り込みが「記述の正解が数字だけです」で止まる | 年号を `"701"` と書いた。`"701年"` にする (§3) |
| 正しい用語が不正解 | 表記揺れ。`accepted_answers` を厚くする (§3) |
| 1 年後に答えが変わっている | 順位・シェアを出題した (§1) |
| 答えが資料の凡例に書いてある | 解答漏洩 (§7) |
| 出典が分からず数値を検算できない | 冒頭コメントに出典と年次が無い (§1) |
| 図の中の ✓ が PDF で豆腐 | 文字で置いた (§2) |
