# 神テスト 問題作成マニュアル — 英語

<!-- canon:subject-value -->`grammar` / `reading` / `eiken` / `mock`<!-- /canon:subject-value -->

**先に [共通編](README.md) を読む。** ここは英語プールの作法だけを書く。
英語は**唯一、実物が 15 冊動いている教科**なので、迷ったら
`scripts/book_exam/materials/meishi1/build_meishi1.py` をそのまま型として写す。

---

## 1. `subject` の使い分け

| 値 | 使うとき |
|---|---|
| `grammar` | 単元別の文法演習。**今の 15 冊は全部これ** |
| `reading` | 長文読解。本文 1 本に設問がぶら下がるもの |
| `eiken` | 英検の級別対策。題名と `level` に級を書く (例 `level: "準1級"`) |
| `mock` | 模試。**本番形式で作れないなら `mock` にしない** (§5) |

★ 教科で探す生徒の動線を優先する。共通テスト形式の長文でも `mock` ではなく
`reading` にしてよい (模試であることは題名で分かる)。

---

## 2. 標準仕様 — 英文法 演習シリーズ (15 冊が実際にこの形)

| 項目 | 値 |
|---|---|
| 問数 | **10 問**ちょうど |
| 形式 | 4 択 (`answer_type: "choice"`, `choice_count: 4`) |
| 配点 | 全問 **2 点** = 20 点 |
| 制限時間 | **20 分** |
| `level` | `"標準"` |
| ページ | 3 ページ (1 ページ 3〜4 問) |
| 単元タグ | 1 冊 1 接頭辞。`MEISHI-FUKASAN` のように `接頭辞-論点` |
| ディレクトリ | `scripts/book_exam/materials/〈ローマ字〉/` (例 `meishi1`) |
| ファイル名 | `英文法_名詞冠詞_第1集.json` / `英文法_名詞冠詞_第1集_問題.pdf` |

既に使っている接頭辞 (**重複させない**):

`BUNSHI` 分詞 / `DAIMEI` 代名詞 / `DOMEI` 動名詞 / `FUTEI` 不定詞 / `HIKAKU` 比較 /
`JISEI` 時制 / `JODO` 助動詞 / `JUDO` 受動態 / `KANKEI` 関係詞 / `KATEI` 仮定法 /
`KEIYO` 形容詞・副詞 / `MEISHI` 名詞・冠詞 / `SETSU` 接続詞 / `TOKUSHU` 特殊構文 /
`ZENCHI` 前置詞

第 2 集を作るときは**接頭辞をそのまま使い、論点だけ新しくする**
(`MEISHI-FUKASAN` は 1 集で使い切っているので 2 集では別の論点を立てる)。

## 3. 設問文の作法 (`verify()` が機械で見る)

```python
QUESTIONS = [
    (1, 1,                                              # 番号, ページ
     "They bought (          ) for their new apartment.",   # 設問文
     ["a furniture", "furnitures", "some furniture", "a few furnitures"],  # 選択肢 4 つ
     3,                                                 # 正解 (1 起算)
     2,                                                 # 配点
     "MEISHI-FUKASAN",                                  # 単元タグ
     "## 🎯 コアイメージ\n…"),                            # 解説
    …
]
```

- **空所は `(          )`** — 半角スペース **6 個以上**を丸括弧で囲む
  (`re.compile(r"\(\s{6,}\)")` で検査)。無いと落ちる
- 選択肢は **4 つ・重複なし**。長さを揃える (正解肢だけ長いと形で当てられる)
- 番号は 1 から連番。ページは戻らない (単調非減少)
- 単元タグは `[A-Z0-9]+-[A-Z0-9]+`

---

## 4. ★ 解説の 4 セクション — **神テストと道場で見出しが違う**

<!-- canon:headings -->
```
## 🎯 コアイメージ
## 🔬 文構造分析
## 📍 正解の根拠
## ❌ 誤答 NG 理由
```
<!-- /canon:headings -->

**この 4 つが順番どおりに 1 回ずつ。1 つでも欠けたら不合格** (build 時の
`verify()` と `check_grammar_books.py` の両方が落とす)。

★★ **3 番目は `## 📍 正解の根拠`。** CLAUDE.md と `server/main.py` の生成プロンプトに
出てくる `## 📍 本文の根拠` は**道場ドリル・模試プール (Railway 側) の作法**であって、
神テストではない。**プールごとに慣行が違う**ので、コピー元を間違えると全問落ちる。

| プール | 3 番目の見出し | 正典 |
|---|---|---|
| **神テスト (この冊子)** | `## 📍 正解の根拠` | `scripts/book_exam/materials/_grammar_build.py` |
| 道場ドリル・模試 (Railway) | `## 📍 本文の根拠` | `server/main.py` の生成プロンプト |

各セクションの中身:

| 見出し | 書くこと |
|---|---|
| 🎯 コアイメージ | その語法・文法の**核**を 2〜3 行。「furniture は数えられない名詞」「by + 交通手段は無冠詞」のように、**次に別の文で会っても使える形**で書く。仲間の語も添える (information / advice / baggage) |
| 🔬 文構造分析 | 正解を入れた**完成文**を 1 行で示し、その下でどこがどう掛かるかを説明する |
| 📍 正解の根拠 | なぜこの選択肢が正解か。1〜2 行 |
| ❌ 誤答 NG 理由 | **誤答 3 つ全部**。正解は書かない |

### 誤答 NG 理由の書式 — ★ 文字列まで照合される

```
## ❌ 誤答 NG 理由
1. a furniture — 不可算名詞に a は付かない。
2. furnitures — 不可算名詞に複数の -s は付かない。
4. a few furnitures — a few は可算用で、-s も付けられない。二重の誤り。
```

- 行頭は `番号. ` + **選択肢の文字列そのまま**。`verify()` が
  `line.startswith(f"{n}. {choices[n-1]}")` で突き合わせる
- **正解の番号を載せない** (載せると落ちる)
- **誤答 3 つを 1 つも欠かさない** (欠けると落ちる)
- 選択肢を後から書き換えたら、**NG 理由の文字列も一緒に直す**。ここが一番よく壊れる

★ 解説は素のテキストで表示される (共通編 §5)。`**太字**` は星ごと出るが、
**紙の解答解説では意味を持つ**ので既存 15 冊はそのまま使っている。倣ってよい。

## 5. 正解位置の配り

- 10 問 4 択なら **各番号 2〜3 回**。偏ると落ちる
- **同じ番号の 3 連続禁止**
- 設問を足したり順番を入れ替えたら**配り直す**。`build_*.py` の冒頭コメントに
  `★ 正解の位置は 1:2 / 2:3 / 3:3 / 4:2` と実際の分布を書き残す慣習

## 6. 長文読解 (`reading`) を作るとき

- **本文は PDF にしか置けない。** 設問文も選択肢も DB に入らない (共通編 §0)
- **解説が引用する英文は本文に実在させる。** 要約を引用符で囲まない。
  引用は本文からのコピーであって、書き直しではない
- 図版 (カレンダー・ポスター・比較表・グラフ・時系列図) は**共通テスト形式なら必須**。
  ただし神テストでは **PDF に刷るしかない** (`question_data.figure_svg` は
  Railway 側ドリルの仕組みで、冊子アプリには無い)
- **図に本文に無い数値を出さない**。出すと設問の根拠が本文外に出る
- 本文が長いと 1 ページに収まらない。`page` を**設問が実際に載っているページ**に
  合わせる (本文のページではない)

## 7. 英検 (`eiken`)

- 題名に級を入れる (「英検準1級 語彙 演習 第1集」)。`level` にも級を書く
- 級ごとに語彙の上限が違う。**上の級の語を下の級の誤答に混ぜない**
  (知らない語は自動的に消せてしまい、実質 3 択になる)

## 8. 模試 (`mock`)

- **本番形式で作る。** 場面設定 300 字以上の会話文 + 誘導連鎖 (前問の結果を次問で使う)。
  各小問が独立した 4 択は「単元別ドリル」であって模試ではない
- 誘導連鎖を入れるなら**大問の中で閉じる**。神テストは大問単位の抽選をしないので
  冊子内で自由に連鎖してよいが、**前問を間違えた生徒が芋づるで全部落ちる**配点にしない

---

## 9. 英語で実際に踏んだ落とし穴

| 症状 | 原因 / 対策 |
|---|---|
| 全問「解説に見出しが無い」で落ちる | 道場プールの `## 📍 本文の根拠` をコピーした (§4) |
| 「NG 理由 3 の語が選択肢と違う」 | 選択肢を直したのに NG 理由の文字列を直していない |
| 正解が 2 つある | 用法が割れる題材を出した (例 `practice (the) piano`)。**形で一意に決まる型だけを使う**。迷ったら出題しない |
| 誤答が実は正しい英語だった | 誤答も 1 つ 1 つ「この文脈で本当に不可か」を敵対的に読む。共通編 §7 の③層 |
| PDF で豆腐 (□) が出る | 日本語フォントに無い文字 (✓ ✗ 等)。使わない |
