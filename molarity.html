モル濃度と希釈

液面の高さは体積 V に、色の濃さはモル濃度 c に比例します。溶質の粒子の数は物質量 n に応じて散らばります。

n = 1.0 mol
V = 1.0 L
c = n / V = 1.0 mol / 1.0 L = 1.00 mol/L
