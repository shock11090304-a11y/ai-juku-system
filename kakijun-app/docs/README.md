# かきじゅん れんしゅう — おうちの方向けガイド

ひらがな・カタカナ・すうじの **正しい書き順** を、iPad で楽しく練習するアプリです。
「線の上をなぞればOK」ではなく、**書く順番・書く向き・書き始めの場所** を判定して、
間違えたその場でやさしく教えます。

## iPad への入れかた（ホーム画面に追加）★重要★

このアプリはホーム画面に追加して使う「ホーム画面アプリ」です。
**必ずこの手順で追加してください。**（Safari のタブのまま使い続けると、
iOS の仕様で練習の記録が消えてしまうことがあります）

1. iPad の **Safari** でアプリの URL を開く
2. 画面上部（アドレスバーの右）の **共有ボタン**（四角から矢印が出ているアイコン □↑）をタップ
3. メニューを下にスクロールして **「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップ
5. ホーム画面に「かきじゅん」のアイコン（オレンジに「あ」）が並びます。
   **以後は必ずこのアイコンから起動してください**

> 一度開けば、機内モードなどネットが無い状態でも全機能が使えます。

## つかいかた

- ホームの絵タイルから **ひらがな / カタカナ / すうじ / せんのれんしゅう** を選びます
- 文字を選ぶと練習が始まります。**光っている丸** が書き始めの場所です
- 同じ文字は「なぞる → うすいお手本 → じぶんで」の3段階で練習が進みます
- 全部書けると花丸と星がもらえます。行をぜんぶクリアするとスタンプがもらえます
- 3回続けて間違えると、自動的にお手本が出て易しくなります。叱る演出はありません

## 保護者メニュー（右上の小さな歯車）

掛け算の問題に答えると入れます（お子さまが誤って触っても入れません）。

- **学習サマリー / 文字別の状況 / つまずき分析**（書き順を間違えやすい文字の上位）
- **設定**: 判定のきびしさ（やさしい・ふつう・きびしい）/ 1回・1日の時間制限 /
  音声・効果音のオンオフ / 学習範囲
- **データのバックアップ**: 「エクスポート」で記録を JSON として書き出せます。
  メモアプリ等に貼って保存しておけば、iPad を替えたときも「インポート」で復元できます。
  **ときどきエクスポートしておくことをおすすめします**（記録の唯一確実なバックアップです）

## 音声について

はじめは iPad の読み上げ機能（合成音声）で案内します。
録音した音声ファイルを `audio/` フォルダに置いて配信し直すと、そちらが優先されます
（詳細は `public/audio/README.md`）。

## うまく動かないとき

- **音が出ない** → 一度画面のどこかをタップしてから試してください（iOS の仕様で、
  最初のタップまで音が出せません）。それでも出ないときは本体のマナースイッチと音量を確認
- **画面が縦のまま** → iPad を横向きにしてください（「よこにしてね」の案内が出ます）
- **記録が消えた** → Safari のタブで使っていませんでしたか？ ホーム画面のアイコンから
  起動してください。エクスポートした JSON があれば保護者メニューから復元できます
- **ホーム画面に追加したら記録が無くなった** → Safari のタブとホーム画面版は
  iOS の仕様で保存領域が別々です。タブで練習した記録は引き継がれません。
  最初からホーム画面版で使い始めるか、タブ側でエクスポート → ホーム画面版で
  インポートしてください
- **とちゅうで「きょうは ここまで！」になった** → 1回15分の既定制限です。
  歯車 → 掛け算 → 設定で「なし」にするか、「リセットして続きを遊べるようにする」を
  押してください
