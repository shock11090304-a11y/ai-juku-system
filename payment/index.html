📜 送信履歴

📨 連絡センターの使い方:
一斉送信: フィルタで対象を絞込 → 件名/本文編集 → 「順次メーラー」で1人ずつ Mail.app 起動 (800ms間隔) or 「BCC一括コピー」で全員のメアドを Gmail 等にペースト
個別送信: 生徒を選んで履歴を確認しながら個別メール作成 (Cmd+Enter で送信)
送信履歴: 過去30日のメール送信履歴 (件名・対象・送信日時) を表示
BCC漏れ防止: 一斉送信は必ず BCC 形式 (CC ではない) なので保護者間で他人のメアドが見えません。

💬 チャット

💡 初回セットアップが必要です
Vercel Dashboard → Storage タブ → Marketplace → Upstash for Redis を「juku-chat」名で Connect。
その後 Settings → Environment Variables で CHAT_SIGNING_SECRET (32文字以上のランダム文字列) と CHAT_ADMIN_PASSWORD (任意のパスワード) を追加 → Redeploy。
管理パスワードを入力 → 🔄 で読込
← 左からスレッドを選択してください
💬 チャットの使い方:
1. 個別送信タブで生徒を選び、「💬 チャット招待リンク発行」ボタンで保護者専用 URL を生成
2. 個別送信メールに招待 URL を貼付けて送信 (本文テンプレに {{chatLink}} 変数も使えます)
3. 保護者が URL からアクセス → このタブで会話
リアルタイム性: 5秒間隔で自動 polling、未読バッジ自動更新
セキュリティ: 招待 URL は HMAC 署名付き、塾長は管理パスワード必須 (URL 漏洩しても塾長アクセスは別系統)
